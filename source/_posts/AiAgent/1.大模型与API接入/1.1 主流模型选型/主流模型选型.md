## 1.1 主流模型选型

### 1.1.1 闭源模型

| 模型 | 提供方 | 突出能力 | 适用场景 | 注意事项 |
|------|--------|----------|----------|----------|
| GPT-4o / GPT-4.1 | OpenAI | 多模态、指令跟随极强、函数调用稳定 | 复杂推理、高质量工具调用、多模态理解 | 成本较高，有速率限制 |
| Claude 3.5 Sonnet / Opus | Anthropic | 超长上下文200K、安全对齐优秀、代码生成强 | 长文档分析、安全敏感场景、代码Agent | 函数调用格式略有不同 |
| Gemini 1.5 Pro / Flash | Google | 原生多模态、百万级上下文、搜索整合 | 视频/音频分析、大规模检索、低成本方案 | 中文能力略逊于GPT/Claude |

**选型建议：**
- 做复杂 Agent 首选 GPT-4o / Claude 3.5 Sonnet。
- 需要处理视频、音频或多模态文件时优先考虑 Gemini。
- 成本敏感、任务简单时可用各家的 Flash 版本（GPT-4o-mini、Claude Haiku、Gemini Flash）。

### 1.1.3 本地部署方案

| 方案 | 适用人群 | 核心优势 | 上手难度 |
|------|----------|----------|----------|
| Ollama | 个人开发者、笔记本部署 | 一条命令启动，自动下载模型，兼容OpenAI API | ★☆☆☆☆ |
| vLLM | 生产环境、高吞吐 | 推理速度极快，支持Tensor并行，可支撑多用户 | ★★★★☆ |
| LM Studio | 完全非技术用户 | 图形化界面，本地下载运行，无任何代码 | ★☆☆☆☆ |

- **Ollama**：Agent 原型开发首选，`ollama run qwen2.5:7b` 直接运行，然后通过 `http://localhost:11434/v1` 与 OpenAI SDK 无缝对接。
- **vLLM**：当你需要把开源模型部署成高性能 API 时使用，支持 `--tool-call-parser` 等特性。
- **LM Studio**：适合产品经理或非开发人员快速体验模型。
