## 10.1 个人知识助手

### 项目定位

把你的笔记、文档、收藏变成「能对话的第二大脑」。问一句，它从你的私域资料里找出答案并标注出处。这是入门 Agent 最经典、最具个人价值的项目。

### 核心能力

- **私域文档 RAG**：本地 Markdown / PDF / Word 一键入库，语义检索；
- **多轮对话 + 记忆**：记住上下文，支持「它刚才说的那个方案再展开讲讲」；
- **来源追溯**：每个回答标注引用了哪篇文档的哪一段，可点击跳转。

### 技术栈

```
前端: Vue 对话界面（流式渲染 + 引用展示）
后端: FastAPI + LlamaIndex / LangChain
检索: Chroma 向量库 + BGE 嵌入 + Reranker
模型: 本地 Ollama(Qwen) 或 云端 API
```

### 关键实现点

1. **入库管道**：用 `SimpleDirectoryReader` 读多种格式 → 递归切分 → 带 `source` 元数据写入 Chroma；
2. **检索增强**：混合检索（语义+BM25）召回 Top-20，Reranker 精排 Top-5 注入 prompt，并要求模型 `[1][2]` 标注引用；
3. **记忆**：短期用滑动窗口保留最近 N 轮，长期把「用户偏好/高频问题」向量化沉淀；
4. **来源跳转**：前端把 `[1]` 映射回原文档锚点。

### 踩坑与优化

- 初期答非所问 → 加 Reranker 后准确率明显提升；
- 长文档被切断 → 改用父子块（小块检索、大块生成）；
- 成本焦虑 → 本地模型跑嵌入+生成，零 API 费用。

### 收获

掌握 RAG 全链路（解析→切分→嵌入→检索→重排→生成）、记忆设计、前端流式交互，是面试时能讲清楚「从 0 到 1」的最佳素材。
