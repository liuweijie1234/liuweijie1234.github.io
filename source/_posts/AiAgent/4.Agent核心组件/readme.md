Agent 区别于普通对话机器人的核心能力，四大支柱模块

记忆系统：短期工作记忆、长期语义记忆、情景记忆、记忆增删改查、摘要压缩、遗忘机制
工具调用：Function Calling 原理、自定义工具封装、参数校验、工具路由选择、错误重试与降级
规划推理：任务拆解方法、依赖关系管理、ReAct 循环、Plan-and-Execute 模式
执行校验：结果合法性校验、失败回滚机制、异常兜底策略
