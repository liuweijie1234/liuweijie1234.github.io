## 5.3 LlamaIndex

LlamaIndex（原 GPT Index）是**围绕 RAG 打造的框架**，尤其在「数据接入 + 索引构建 + 检索」方面极其顺手。

### 核心定位

如果说 LangChain 是「通用 LLM 应用工具箱」，LlamaIndex 就是「**把你的私有数据变成可被 LLM 查询的知识引擎**」的专家。

### 数据连接器（Data Connectors）

LlamaIndex 的强项是「什么数据都能吃」：文件系统、Notion、Slack、数据库、PDF、网页……统一封装成 `Document`，再切成 `Node`（带元数据的块）。

```python
from llama_index.core import SimpleDirectoryReader

docs = SimpleDirectoryReader("./data").load_data()  # 一键读多种格式
```

### 索引（Index）

- **VectorStoreIndex**：最常用的向量索引，支撑语义检索。
- 还有树索引（TreeIndex）、关键词索引（KeywordTableIndex）、摘要索引等，针对不同查询类型。
- 索引可持久化（存本地 / 向量库），下次直接加载不用重建。

### 基于 Agent 的查询引擎

LlamaIndex 不只是「检索→填空」，还能构建**查询引擎 / 子问题引擎**：

- `QueryEngine`：回答问题，自动检索相关节点后生成；
- `SubQuestionQueryEngine`：把复杂问题拆成子问题，分别检索再汇总（本质是 RAG + 规划）；
- 新版本也提供 `Agent` / `Workflow`，支持工具调用和多步推理，向 Agent 方向演进。

```python
from llama_index.core import VectorStoreIndex

index = VectorStoreIndex.from_documents(docs)
query_engine = index.as_query_engine()
print(query_engine.query("公司年假政策是怎样的？"))
```

### 和 LangChain / LangGraph 的关系

- LlamaIndex 擅长**数据侧（接入、索引、检索）**，LangChain/LangGraph 擅长**编排侧（流程、Agent）**；
- 常见组合：用 LlamaIndex 做 RAG 检索器，把结果喂给 LangGraph 编排的 Agent；
- 选 LlamaIndex 当你的核心需求是「私有知识问答 / RAG」；选 LangGraph 当核心需求是「多步可控 Agent」。

### 一句话

LlamaIndex = RAG 专用框架，把「接数据 → 建索引 → 精准检索 → 回答」做到极致，是做知识库问答的首选。
