OpenClaw
定位：开源自托管的个人自主 Agent 系统，主打 “本地运行、有真实执行力、24 小时在线”
核心特点：它不是聊天框里的 “顾问”，是能真干活的 “AI 员工”—— 可以直接操作电脑终端、管理文件、发邮件、控制浏览器，通过微信 / Telegram 就能远程发指令
核心架构：Gateway（多渠道消息接入）+ Agent（决策大脑）+ Skills（技能包）+ Memory（持久记忆）四大模块
学习价值：能直观感受 “有执行力的 Agent” 长什么样，理解 Skill 封装、本地私有化部署、多渠道交互的设计思路
注意：它偏向个人自动化场景，和企业级开发框架 LangGraph 定位不同，适合拓展视野，不作为企业开发主力框架学习
