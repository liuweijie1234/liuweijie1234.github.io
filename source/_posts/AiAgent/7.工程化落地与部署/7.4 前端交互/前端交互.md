## 7.4 前端交互

好用的 Agent 产品，前端体验占一半。尤其是「流式渲染」和「过程可视化」。

### 1. Vue 集成 Agent 对话组件

以 Vue 3 + SSE 为例，接收流式 token 并实时渲染：

```vue
<script setup>
import { ref } from "vue";
const input = ref("");
const answer = ref("");

async function send() {
  answer.value = "";
  const res = await fetch("/agent/chat/stream", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ message: input.value }),
  });
  const reader = res.body.getReader();
  const decoder = new TextDecoder();
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    const chunk = decoder.decode(value);
    chunk.split("\n\n").forEach(line => {
      if (line.startsWith("data:")) answer.value += line.slice(5);
    });
  }
}
</script>
```

### 2. 工具调用状态展示（步骤可视化）

用户最怕「黑盒等半天」。把 Agent 的「思考/调工具/观察」实时展示出来，信任感大增：

```
🤔 思考：需要先查订单状态
🔧 调用 tools.query_order(订单号: NO123)
📦 观察：订单已发货，预计明天到
💡 回答：您的订单已发货，预计明天送达
```

实现：后端在流式里额外推送「事件类型」消息（如 `{type: "tool_call", name: "query_order"}`），前端据此渲染不同样式卡片。

### 3. 操作确认与用户干预 UI

对高权限操作（发邮件、退款、删数据），前端要弹「确认框」：

- 后端在工具执行前返回「需确认」事件，前端暂停等待用户点「允许/拒绝」；
- 用户拒绝则回灌「用户拒绝了该操作」给 Agent，让它换方案（Human-in-the-loop）。

### 4. Markdown / 代码高亮

Agent 输出常含代码、表格、列表。前端用 `marked` + `highlight.js` 渲染 Markdown，代码块带高亮和「复制」按钮，体验拉满。

### 经验

- 流式渲染是标配，别让用户干等；
- 「过程可视化」比「只给最终答案」更能建立信任，尤其企业场景；
- 高风险操作必须前端确认，这是安全底线（见「权限与审计」）。
