## 语法

Python 没有 C 语言风格的 `?:` 三元运算符，而是使用**条件表达式**：

```python
值1 if 条件 else 值2
```

条件为真时整个表达式取 `值1`，否则取 `值2`。

## 示例

```python
# 取两数较大值
a, b = 10, 20
max_val = a if a > b else b   # 20

# 替代简单的 if/else 赋值
score = 75
result = "及格" if score >= 60 else "不及格"   # '及格'
```

## 嵌套（不推荐过深）

```python
x = 0
sign = "正数" if x > 0 else ("零" if x == 0 else "负数")   # '零'
```

## 常见使用场景

```python
# 1. 列表推导式中做条件转换
nums = [1, -2, 3, -4]
abs_nums = [n if n >= 0 else -n for n in nums]   # [1, 2, 3, 4]

# 2. 函数默认值处理
def greet(name=None):
    return f"Hello, {name if name else 'Guest'}"

# 3. lambda 中使用
max_fn = lambda a, b: a if a > b else b
```

## 注意事项

- 条件表达式优先级较低，与其他运算符混用时建议加括号。
- 只适合简单的二选一逻辑，复杂分支应使用 `if/elif/else` 语句，保证可读性。
