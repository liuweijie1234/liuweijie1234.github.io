## 什么是猴子补丁

猴子补丁指**在运行时动态替换模块、类或实例的属性/方法**，而不修改源代码。
Python 中一切皆对象，模块和类的属性都可以在运行期被重新赋值，这是猴子补丁的基础。

## 基本示例

```python
class Dog:
    def bark(self):
        return "汪汪"

def new_bark(self):
    return "喵喵"

Dog.bark = new_bark      # 运行时替换类方法
print(Dog().bark())      # 喵喵
```

## 典型应用场景

### 1. gevent 替换标准库为非阻塞实现

```python
from gevent import monkey
monkey.patch_all()   # 将 socket、time.sleep 等替换为协程友好的版本

import requests      # 之后的网络 IO 自动变为非阻塞
```

### 2. 单元测试中打桩（mock）

```python
from unittest import mock

# 临时替换 requests.get，避免真实网络请求
with mock.patch("requests.get") as fake_get:
    fake_get.return_value.status_code = 200
    import requests
    assert requests.get("http://example.com").status_code == 200
```

### 3. 给第三方库紧急修复 bug

在不改动第三方库源码（升级困难）时，用自己的实现覆盖有问题的函数。

## 注意事项

- 补丁在**运行时全局生效**，可能影响其他依赖该对象的代码，排查问题困难。
- 补丁应尽早执行（如 `gevent.monkey.patch_all()` 要放在所有 import 之前）。
- 能通过继承、装饰器、依赖注入解决的问题，优先不用猴子补丁。
