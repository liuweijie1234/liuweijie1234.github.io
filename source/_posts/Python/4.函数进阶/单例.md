单例模式：保证一个类**只有一个实例**，并提供全局访问点。常用于配置对象、数据库连接池、日志对象等。

## 4 种单例模式

### 1. 模块级单例（最 Pythonic）

Python 模块在首次 import 后会被缓存（`sys.modules`），天然是单例。

```python
# config.py
class Config:
    pass

config = Config()

# 其他文件中
# from config import config   # 拿到的永远是同一个实例
```

### 2. 重写 __new__

```python
class Singleton:
    _instance = None

    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

a = Singleton()
b = Singleton()
print(a is b)   # True
```

> 注意：每次实例化 `__init__` 仍会被重复执行；多线程场景需加锁：

```python
import threading

class Singleton:
    _instance = None
    _lock = threading.Lock()

    def __new__(cls):
        if cls._instance is None:
            with cls._lock:                 # 双重检查加锁
                if cls._instance is None:
                    cls._instance = super().__new__(cls)
        return cls._instance
```

### 3. 装饰器实现

```python
import functools

def singleton(cls):
    instances = {}
    @functools.wraps(cls)
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    return get_instance

@singleton
class Database:
    pass

print(Database() is Database())   # True
```

### 4. 元类实现

```python
class SingletonMeta(type):
    _instances = {}

    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class Logger(metaclass=SingletonMeta):
    pass

print(Logger() is Logger())   # True
```

元类方式在 `__call__` 中拦截实例化过程，`__init__` 只会执行一次，是功能最完整的实现。

## 对比

| 方式 | 优点 | 缺点 |
| --- | --- | --- |
| 模块级 | 最简单、线程安全（import 有锁） | 无法延迟传参初始化 |
| `__new__` | 直观 | `__init__` 会重复执行 |
| 装饰器 | 对类无侵入 | 被装饰后类变成函数，无法再继承 |
| 元类 | 最完整，`__init__` 只执行一次 | 理解成本高 |
