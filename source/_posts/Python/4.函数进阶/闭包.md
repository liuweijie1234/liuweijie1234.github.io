## 什么是闭包

闭包（Closure）是指**内层函数引用了外层函数的局部变量，并且外层函数把内层函数作为返回值返回**。
即使外层函数已经执行结束，被引用的变量依然被内层函数"记住"。

构成闭包的三个条件：

1. 存在函数嵌套；
2. 内层函数引用了外层函数的变量（自由变量）；
3. 外层函数返回内层函数。

## 基本示例

```python
def outer(x):
    def inner(y):
        return x + y     # inner 引用了外层变量 x
    return inner

add5 = outer(5)          # outer 已执行完毕，但 x=5 被保留
print(add5(3))           # 8
print(add5.__closure__)  # (<cell at 0x...: int object at ...>,)
print(add5.__closure__[0].cell_contents)  # 5
```

## nonlocal：修改闭包变量

内层函数直接对外层变量赋值会被当作新的局部变量，需要用 `nonlocal` 声明：

```python
def counter():
    count = 0
    def add():
        nonlocal count   # 声明修改外层变量
        count += 1
        return count
    return add

c = counter()
print(c(), c(), c())   # 1 2 3
```

## 经典陷阱：循环变量延迟绑定

```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])          # [2, 2, 2]，不是 [0, 1, 2]

# 解决：用默认参数在定义时绑定
funcs = [lambda i=i: i for i in range(3)]
print([f() for f in funcs])          # [0, 1, 2]
```

原因：闭包保存的是变量的引用而不是值，循环结束后 `i` 的最终值是 2。

## 应用场景

- **装饰器**：装饰器的实现就是闭包（wrapper 引用了 func）。
- **工厂函数**：如上面的 `outer(5)` 生成定制函数。
- **保存状态**：代替只有少量状态的小型类（如计数器）。
