## 说明

动态规划适用于**有重叠子问题和最优子结构**的问题：把大问题拆成子问题，记录子问题的解避免重复计算。

解题四步：

1. 定义状态：`dp[i]` 表示什么；
2. 状态转移方程：`dp[i]` 如何由前面的状态推出；
3. 初始化边界条件；
4. 确定遍历顺序，返回答案。

## 入门：斐波那契

```python
# 朴素递归 O(2^n)，大量重复计算
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)

# 记忆化递归（自顶向下）
from functools import lru_cache

@lru_cache(maxsize=None)
def fib_memo(n):
    return n if n < 2 else fib_memo(n - 1) + fib_memo(n - 2)

# 递推 + 滚动变量（自底向上，空间 O(1)）
def fib_dp(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

## 爬楼梯

每次可以爬 1 或 2 级，问爬到 n 级有多少种方法。
状态转移：`dp[i] = dp[i-1] + dp[i-2]`。

```python
def climb_stairs(n: int) -> int:
    a, b = 1, 1          # dp[0]=1, dp[1]=1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b

climb_stairs(5)   # 8
```

## 打家劫舍（不能偷相邻的房子）

状态转移：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`。

```python
def rob(nums: list) -> int:
    prev, cur = 0, 0
    for x in nums:
        prev, cur = cur, max(cur, prev + x)
    return cur

rob([2, 7, 9, 3, 1])   # 12（2+9+1）
```

## 最长递增子序列（LIS）

`dp[i]`：以 `nums[i]` 结尾的最长递增子序列长度。

```python
def length_of_lis(nums: list) -> int:
    if not nums:
        return 0
    dp = [1] * len(nums)
    for i in range(1, len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)     # O(n²)

length_of_lis([10, 9, 2, 5, 3, 7, 101, 18])   # 4（2,3,7,18）
```

## 0-1 背包（模板）

n 件物品，容量 W，每件物品重 `w[i]`、价值 `v[i]`，每件最多选一次：

```python
def knapsack(weights, values, W):
    dp = [0] * (W + 1)                 # dp[j]: 容量 j 时的最大价值
    for w, v in zip(weights, values):
        for j in range(W, w - 1, -1):  # 0-1 背包必须倒序遍历容量
            dp[j] = max(dp[j], dp[j - w] + v)
    return dp[W]

knapsack([1, 3, 4], [15, 20, 30], 4)   # 35
```

## 总结

- 重叠子问题 → 记忆化（`@lru_cache`）或递推表。
- 大多数一维 DP 可以用滚动变量把空间从 O(n) 降到 O(1)。
- 0-1 背包倒序遍历容量、完全背包正序遍历容量。
