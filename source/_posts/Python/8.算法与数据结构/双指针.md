## 说明

双指针是用两个索引配合遍历，把 O(n²) 的暴力解优化到 O(n) 的常用技巧。常见三种形式：

1. **对撞指针**：从两端向中间移动（要求数组有序或处理回文）。
2. **快慢指针**：同向移动、速度不同（链表判环、原地删除）。
3. **滑动窗口**：右指针扩张、左指针收缩，维护一个可行区间。

## 对撞指针

### 有序数组两数之和

```python
def two_sum_sorted(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        s = nums[lo] + nums[hi]
        if s == target:
            return [lo, hi]
        elif s < target:
            lo += 1
        else:
            hi -= 1

two_sum_sorted([1, 3, 5, 9], 8)   # [1, 2]
```

### 验证回文串

```python
def is_palindrome(s: str) -> bool:
    lo, hi = 0, len(s) - 1
    while lo < hi:
        if s[lo] != s[hi]:
            return False
        lo += 1
        hi -= 1
    return True
```

## 快慢指针

### 原地移除元素

```python
def remove_element(nums, val):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != val:
            nums[slow] = nums[fast]
            slow += 1
    return slow   # 新长度
```

## 滑动窗口

### 无重复字符的最长子串

```python
def length_of_longest_substring(s: str) -> int:
    window = set()
    left = best = 0
    for right, ch in enumerate(s):
        while ch in window:          # 出现重复，收缩左边界
            window.discard(s[left])
            left += 1
        window.add(ch)
        best = max(best, right - left + 1)
    return best

length_of_longest_substring("abcabcbb")   # 3（'abc'）
```

## 使用套路总结

- 数组**有序** + 找两数关系 → 对撞指针。
- **原地**修改数组/链表 → 快慢指针。
- 求**连续子串/子数组**的最值 → 滑动窗口。
