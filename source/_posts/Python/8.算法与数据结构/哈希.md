## 说明

哈希表通过哈希函数把 key 映射到存储位置，实现平均 **O(1)** 的插入、删除、查找。
Python 中的 `dict` 和 `set` 都是哈希表实现：

- key 必须是**可哈希**（不可变）对象：数字、字符串、元组等；list、dict 不能作 key。
- 哈希冲突由解释器内部处理（开放寻址法）。
- Python 3.7+ `dict` 保持插入顺序。

## 经典题目

### 1. 两数之和（LeetCode 1）

```python
def two_sum(nums: list, target: int):
    seen = {}                      # 值 -> 下标
    for i, x in enumerate(nums):
        if target - x in seen:     # O(1) 查找
            return [seen[target - x], i]
        seen[x] = i

two_sum([2, 7, 11, 15], 9)   # [0, 1]
```

暴力双重循环是 O(n²)，用哈希表以空间换时间降为 O(n)。

### 2. 统计词频

```python
from collections import Counter

words = ["a", "b", "a", "c", "b", "a"]
Counter(words)                  # Counter({'a': 3, 'b': 2, 'c': 1})
Counter(words).most_common(2)   # [('a', 3), ('b', 2)]
```

### 3. 数组去重 / 判断重复

```python
nums = [1, 2, 2, 3]
len(nums) != len(set(nums))     # True，存在重复

list(dict.fromkeys(nums))       # [1, 2, 3]，去重且保持顺序
```

### 4. 字母异位词分组

```python
from collections import defaultdict

def group_anagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        groups[tuple(sorted(s))].append(s)   # 排序后作为 key
    return list(groups.values())

group_anagrams(["eat", "tea", "tan", "ate"])
# [['eat', 'tea', 'ate'], ['tan']]
```

## 常用工具

| 工具 | 用途 |
| --- | --- |
| `dict.get(k, default)` | 取值不存在时返回默认值 |
| `dict.setdefault(k, default)` | 不存在时先设置再返回 |
| `collections.defaultdict` | 自动初始化默认值 |
| `collections.Counter` | 计数器 |
| `set` 交并差：`&` `\|` `-` | 集合运算，均为 O(len) |

## 注意事项

- 哈希表是**以空间换时间**的典型结构。
- 自定义类作 key 需正确实现 `__hash__` 与 `__eq__`。
- 最坏情况下（大量冲突）操作退化为 O(n)，但实际很少发生。
