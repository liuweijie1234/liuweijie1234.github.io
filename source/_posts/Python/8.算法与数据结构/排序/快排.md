## 思想

快速排序采用**分治**策略：

1. 选一个基准值（pivot）；
2. 把比 pivot 小的放左边、大的放右边（分区 partition）；
3. 对左右两部分递归执行上述过程。

- 平均时间复杂度：O(n log n)
- 最坏（每次 pivot 都取到最值，如对有序数组取首元素）：O(n²)
- 空间：O(log n)（递归栈），不稳定排序

## 简洁版（易于理解，额外空间 O(n)）

```python
def quick_sort(nums: list) -> list:
    if len(nums) <= 1:
        return nums
    pivot = nums[len(nums) // 2]
    left = [x for x in nums if x < pivot]
    mid = [x for x in nums if x == pivot]
    right = [x for x in nums if x > pivot]
    return quick_sort(left) + mid + quick_sort(right)

quick_sort([3, 6, 1, 8, 2, 9])   # [1, 2, 3, 6, 8, 9]
```

## 原地分区版（面试手写版）

```python
def quick_sort_inplace(nums, lo=0, hi=None):
    if hi is None:
        hi = len(nums) - 1
    if lo >= hi:
        return
    p = partition(nums, lo, hi)
    quick_sort_inplace(nums, lo, p - 1)
    quick_sort_inplace(nums, p + 1, hi)

def partition(nums, lo, hi):
    pivot = nums[hi]              # 取末尾为基准
    i = lo                        # i 左边都是 < pivot 的元素
    for j in range(lo, hi):
        if nums[j] < pivot:
            nums[i], nums[j] = nums[j], nums[i]
            i += 1
    nums[i], nums[hi] = nums[hi], nums[i]
    return i

nums = [3, 6, 1, 8, 2, 9]
quick_sort_inplace(nums)
print(nums)   # [1, 2, 3, 6, 8, 9]
```

## 优化点

- **随机选取 pivot**，避免对近乎有序数组退化为 O(n²)：

```python
import random

def partition_random(nums, lo, hi):
    k = random.randint(lo, hi)
    nums[k], nums[hi] = nums[hi], nums[k]
    return partition(nums, lo, hi)
```

- 小区间改用插入排序；三路快排处理大量重复元素。

## 实际开发

实际业务中直接使用内置的 `sorted()` / `list.sort()`，底层是 Timsort（归并 + 插入的混合算法，稳定，O(n log n)）。手写快排主要用于面试。
