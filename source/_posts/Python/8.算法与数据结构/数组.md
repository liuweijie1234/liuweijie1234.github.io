## 说明

数组是**连续内存、支持下标随机访问**的线性结构。Python 中通常用 `list` 充当动态数组：

- 按下标访问：O(1)
- 尾部追加/删除（append/pop）：均摊 O(1)
- 头部/中间插入删除：O(n)（需要搬移元素）
- 查找元素（`x in list`）：O(n)

## 常见面试题

### 1. 移除有序数组中的重复项（原地，双指针）

```python
def remove_duplicates(nums: list) -> int:
    if not nums:
        return 0
    slow = 0
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]
    return slow + 1   # 新长度

nums = [1, 1, 2, 2, 3]
n = remove_duplicates(nums)   # 3, nums 前 3 位为 [1, 2, 3]
```

### 2. 合并两个有序数组

```python
def merge(a: list, b: list) -> list:
    i = j = 0
    res = []
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            res.append(a[i]); i += 1
        else:
            res.append(b[j]); j += 1
    res.extend(a[i:]); res.extend(b[j:])
    return res

merge([1, 3, 5], [2, 4, 6])   # [1, 2, 3, 4, 5, 6]
```

### 3. 最大子数组和（Kadane 算法，O(n)）

```python
def max_sub_array(nums: list) -> int:
    cur = best = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)     # 要么接上前面，要么重新开始
        best = max(best, cur)
    return best

max_sub_array([-2, 1, -3, 4, -1, 2, 1, -5, 4])   # 6（[4,-1,2,1]）
```

### 4. 轮转数组（切片）

```python
def rotate(nums: list, k: int) -> list:
    k %= len(nums)
    return nums[-k:] + nums[:-k]

rotate([1, 2, 3, 4, 5], 2)   # [4, 5, 1, 2, 3]
```
