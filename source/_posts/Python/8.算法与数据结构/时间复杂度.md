## 时间复杂度

时间复杂度用大 O 记号描述**算法执行次数随数据规模 n 增长的趋势**（忽略常数和低阶项）。

常见复杂度由快到慢：

| 复杂度 | 名称 | 典型例子 |
| --- | --- | --- |
| O(1) | 常数 | 数组按下标取值、dict 查找 |
| O(log n) | 对数 | 二分查找 |
| O(n) | 线性 | 遍历列表 |
| O(n log n) | 线性对数 | 快排、归并排序（平均） |
| O(n²) | 平方 | 冒泡排序、双重循环 |
| O(2ⁿ) | 指数 | 朴素递归求斐波那契 |

## 示例分析

```python
# O(1)
def get_first(nums):
    return nums[0]

# O(n)
def total(nums):
    s = 0
    for x in nums:      # 循环 n 次
        s += x
    return s

# O(n²)
def has_dup(nums):
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] == nums[j]:
                return True
    return False

# O(log n)：每轮把范围缩小一半
def binary_search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

## 空间复杂度

描述算法**额外占用内存**随 n 增长的趋势：

```python
# 空间 O(1)：只用了固定几个变量
def total(nums):
    s = 0
    for x in nums:
        s += x
    return s

# 空间 O(n)：新建了与输入等长的列表
def double(nums):
    return [x * 2 for x in nums]

# 递归的空间复杂度还要计入调用栈深度
def fact(n):            # 栈深 n，空间 O(n)
    return 1 if n <= 1 else n * fact(n - 1)
```

## Python 常用操作复杂度速查

| 操作 | 复杂度 |
| --- | --- |
| `list[i]`、`list.append` | O(1) |
| `x in list` | O(n) |
| `list.insert(0, x)`、`list.pop(0)` | O(n) |
| `x in set` / `x in dict` | 平均 O(1) |
| `list.sort()` | O(n log n) |
| `collections.deque` 两端进出 | O(1) |
