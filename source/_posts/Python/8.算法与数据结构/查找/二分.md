## 思想

二分查找要求序列**有序**，每次与中间元素比较，将查找范围缩小一半，时间复杂度 O(log n)。

## 标准写法（闭区间 [lo, hi]）

```python
def binary_search(nums: list, target) -> int:
    lo, hi = 0, len(nums) - 1
    while lo <= hi:                    # 闭区间用 <=
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1

binary_search([1, 3, 5, 7, 9], 7)   # 3
binary_search([1, 3, 5, 7, 9], 4)   # -1
```

## 查找左边界（第一个等于 target 的位置）

```python
def left_bound(nums, target):
    lo, hi = 0, len(nums)
    while lo < hi:                     # 左闭右开
        mid = (lo + hi) // 2
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo if lo < len(nums) and nums[lo] == target else -1

left_bound([1, 2, 2, 2, 3], 2)   # 1
```

## 递归写法

```python
def bsearch(nums, target, lo=0, hi=None):
    if hi is None:
        hi = len(nums) - 1
    if lo > hi:
        return -1
    mid = (lo + hi) // 2
    if nums[mid] == target:
        return mid
    if nums[mid] < target:
        return bsearch(nums, target, mid + 1, hi)
    return bsearch(nums, target, lo, mid - 1)
```

## 标准库 bisect

```python
import bisect

nums = [1, 3, 3, 5, 7]
bisect.bisect_left(nums, 3)    # 1，第一个 >= 3 的位置
bisect.bisect_right(nums, 3)   # 3，第一个 > 3 的位置
bisect.insort(nums, 4)         # 插入并保持有序: [1, 3, 3, 4, 5, 7]
```

## 常见坑

- `while lo <= hi` 与 `while lo < hi` 必须与区间开闭定义配套，否则死循环或漏解。
- `mid = (lo + hi) // 2` 在 Python 中不会整数溢出（其他语言常写成 `lo + (hi - lo) // 2`）。
- 二分不仅用于查值，还可用于"二分答案"：在单调答案空间中找临界点。
