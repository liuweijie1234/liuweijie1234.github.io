## 说明

递归是函数**直接或间接调用自身**的编程技巧。写递归的两个要素：

1. **终止条件（base case）**：防止无限递归；
2. **递推关系**：把规模 n 的问题转化为更小规模的同类问题。

Python 默认递归深度限制约 1000 层（`sys.getrecursionlimit()`），超出抛出 `RecursionError`。

## 基本示例

```python
# 阶乘
def fact(n: int) -> int:
    if n <= 1:          # 终止条件
        return 1
    return n * fact(n - 1)

# 遍历目录树
import os

def walk(path, depth=0):
    for name in os.listdir(path):
        full = os.path.join(path, name)
        print("  " * depth + name)
        if os.path.isdir(full):
            walk(full, depth + 1)
```

## 实际业务：无限级分类（树形结构）

后台管理中常见的部门树、评论树、商品分类树，用递归把平铺数据组装成树：

```python
data = [
    {"id": 1, "parent_id": 0, "name": "电子产品"},
    {"id": 2, "parent_id": 1, "name": "手机"},
    {"id": 3, "parent_id": 1, "name": "电脑"},
    {"id": 4, "parent_id": 3, "name": "笔记本"},
]

def build_tree(items, parent_id=0):
    tree = []
    for item in items:
        if item["parent_id"] == parent_id:
            children = build_tree(items, item["id"])
            if children:
                item["children"] = children
            tree.append(item)
    return tree

import json
print(json.dumps(build_tree(data), ensure_ascii=False, indent=2))
```

## 实际业务：递归处理嵌套字典（如批量改 key）

处理嵌套 JSON / 配置（例如遇到与保留字冲突的 key 需要批量替换）：

```python
def rename_key(obj, old_key, new_key):
    if isinstance(obj, dict):
        return {
            (new_key if k == old_key else k): rename_key(v, old_key, new_key)
            for k, v in obj.items()
        }
    if isinstance(obj, list):
        return [rename_key(x, old_key, new_key) for x in obj]
    return obj

rename_key({"type": 1, "data": [{"type": 2}]}, "type", "type_")
# {'type_': 1, 'data': [{'type_': 2}]}
```

## 递归的问题与优化

- **重复计算**：如朴素斐波那契 O(2ⁿ)，用 `@functools.lru_cache` 记忆化。
- **栈溢出**：深度过大时改成迭代（显式用栈/队列），或 `sys.setrecursionlimit()`（治标）。
- Python **没有尾递归优化**，尾递归写法也不会省栈。

```python
# 递归转迭代示例：阶乘
def fact_iter(n):
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result
```
