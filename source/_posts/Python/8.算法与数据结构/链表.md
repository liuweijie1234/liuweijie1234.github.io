## 说明

链表由节点组成，每个节点保存数据和指向下一个节点的引用。

- 插入/删除（已知位置）：O(1)
- 随机访问/查找：O(n)
- 与数组相比：不需要连续内存，扩容无成本，但不支持下标访问。

## 节点定义

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def build(nums):
    """由列表构建链表，返回头节点"""
    dummy = ListNode()
    cur = dummy
    for x in nums:
        cur.next = ListNode(x)
        cur = cur.next
    return dummy.next

def to_list(head):
    res = []
    while head:
        res.append(head.val)
        head = head.next
    return res
```

## 经典题目

### 1. 反转链表（迭代）

```python
def reverse(head):
    prev, cur = None, head
    while cur:
        cur.next, prev, cur = prev, cur, cur.next
    return prev

to_list(reverse(build([1, 2, 3])))   # [3, 2, 1]
```

### 2. 判断环形链表（快慢指针）

```python
def has_cycle(head) -> bool:
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False
```

### 3. 合并两个有序链表

```python
def merge(l1, l2):
    dummy = cur = ListNode()
    while l1 and l2:
        if l1.val <= l2.val:
            cur.next, l1 = l1, l1.next
        else:
            cur.next, l2 = l2, l2.next
        cur = cur.next
    cur.next = l1 or l2
    return dummy.next
```

### 4. 找中间节点（快慢指针）

```python
def middle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow   # 偶数个节点时返回第二个中间节点
```

### 5. 删除倒数第 N 个节点（双指针 + 哑节点）

```python
def remove_nth_from_end(head, n):
    dummy = ListNode(0, head)
    fast = slow = dummy
    for _ in range(n):
        fast = fast.next
    while fast.next:
        fast, slow = fast.next, slow.next
    slow.next = slow.next.next
    return dummy.next
```

## 技巧总结

- **哑节点（dummy）**：统一处理头节点可能被修改的情况。
- **快慢指针**：找中点、判环、找倒数第 k 个。
- Python 标准库 `collections.deque` 底层是双向链表结构，两端操作 O(1)。
