## 一、测试体系

Django 基于 Python `unittest`，提供 `django.test` 增强：测试数据库、客户端、fixtures。推荐用 `pytest` + `pytest-django` 获得更友好的断言与夹具。

## 二、单元测试示例

```python
from django.test import TestCase
from django.urls import reverse
from .models import Article

class ArticleModelTest(TestCase):
    def test_create(self):
        a = Article.objects.create(title='t', body='b')
        self.assertEqual(str(a), 't')

class ArticleViewTest(TestCase):
    def test_detail_200(self):
        a = Article.objects.create(title='t', body='b')
        resp = self.client.get(reverse('blog:detail', args=[a.pk]))
        self.assertEqual(resp.status_code, 200)
```

`TestCase` 会自动创建/销毁测试数据库，每个测试隔离。

## 三、测试客户端

```python
from django.test import Client
c = Client()
resp = c.post('/login/', {'username': 'u', 'password': 'p'})
assert resp.status_code == 302
```

## 四、pytest 写法（推荐）

```python
import pytest
from .models import Article

@pytest.mark.django_db
def test_article_create():
    a = Article.objects.create(title='x', body='y')
    assert Article.objects.count() == 1
```

`pytest-django` 的 `@pytest.mark.django_db` 自动处理数据库。

## 五、测试层次建议

- **Model 测试**：校验方法、约束、信号副作用。
- **View 测试**：状态码、上下文、重定向、权限。
- **Serializer/Form 测试**：校验规则。
- **集成/E2E**：关键业务链路（可用 Playwright）。

## 六、覆盖率与 CI

```bash
pip install pytest pytest-django pytest-cov
pytest --cov=blog --cov-report=html
```

把测试接入 CI（GitHub Actions），每次 push 自动跑。

## 七、最佳实践

- 测试要快、独立、可重复；不要在测试里依赖外部网络，用 `responses`/`requests-mock` mock。
- 用 factory_boy 生成测试数据，替代手写 fixtures。
- 先写失败的测试（TDD）或先写功能后补测试，但覆盖率要守住在合理阈值（如 80%+）。
