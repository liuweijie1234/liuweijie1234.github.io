## 一、最小应用

```python
from flask import Flask
app = Flask(__name__)

@app.route('/')
def index():
    return 'Hello Flask'

if __name__ == '__main__':
    app.run(debug=True)
```

`@app.route` 把 URL 规则绑定到视图函数；启动后访问 `http://127.0.0.1:5000/`。

## 二、URL 规则与转换器

```python
@app.route('/user/<username>')
def profile(username):
    return f'user: {username}'

@app.route('/post/<int:post_id>')
def show_post(post_id):
    return f'post id: {post_id}'
```

内置转换器：`string`(默认)、`int`、`float`、`path`、`uuid`。

## 三、HTTP 方法

```python
@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        return 'handle login'
    return 'show form'
```

`methods` 未指定时默认只接受 GET。

## 四、反向解析 url_for

```python
from flask import url_for, redirect

@app.route('/')
def index():
    return redirect(url_for('profile', username='bob'))
```

`url_for(视图函数名, **参数)` 生成 URL，避免硬编码。

## 五、类视图（MethodView）

```python
from flask.views import MethodView

class ArticleAPI(MethodView):
    def get(self, id): ...
    def post(self): ...

app.add_url_rule('/article/<id>', view_func=ArticleAPI.as_view('article'))
```

## 六、应用工厂与配置

```python
def create_app(config):
    app = Flask(__name__)
    app.config.from_object(config)
    from .views import bp
    app.register_blueprint(bp)
    return app
```

## 七、最佳实践

- 用**应用工厂 + 蓝图**组织中大型项目，不要全写在一个文件。
- 视图保持薄，业务逻辑放 service 模块。
- 统一错误处理：`@app.errorhandler(404)` / `500`。
- 上线关闭 `debug=True`，改用生产服务器（见 `9.部署/部署.md`）。
