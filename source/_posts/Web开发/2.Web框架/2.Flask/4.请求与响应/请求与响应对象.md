## 一、request 对象

`flask.request` 封装了当前请求的上下文（线程局部变量），在视图里直接 import 使用。

```python
from flask import request

@app.route('/upload', methods=['POST'])
def upload():
    q = request.args.get('q')              # 查询参数 ?q=
    name = request.form.get('name')        # 表单字段
    f = request.files.get('file')          # 上传文件
    ua = request.headers.get('User-Agent')
    data = request.get_json()             # JSON 请求体
```

## 二、request 常用属性

| 属性 | 说明 |
|------|------|
| `request.method` | GET/POST/... |
| `request.args` | 查询字符串 |
| `request.form` | 表单数据 |
| `request.json` / `get_json()` | JSON 体 |
| `request.files` | 上传文件 |
| `request.headers` | 请求头 |
| `request.cookies` | Cookie |
| `request.remote_addr` | 客户端 IP |

## 三、响应对象

```python
from flask import make_response, jsonify, redirect, url_for

@app.route('/api')
def api():
    return jsonify({'ok': True})           # 自动设 Content-Type

@app.route('/raw')
def raw():
    resp = make_response('hello')
    resp.headers['X-Token'] = 'abc'
    resp.set_cookie('k', 'v')
    return resp
```

返回字符串时 Flask 自动包成 `Response`；返回元组 `(响应, 状态码, 头)` 可定制：

```python
return 'created', 201, {'X-Foo': 'bar'}
```

## 四、文件上传

```python
@app.route('/upload', methods=['POST'])
def upload():
    f = request.files['file']
    f.save(f'/tmp/{f.filename}')
```

配合 `werkzeug.utils.secure_filename` 防路径穿越。

## 五、会话 Session

```python
from flask import session
app.secret_key = 'change-me'

@app.route('/login')
def login():
    session['user'] = 'bob'
    return 'ok'
```

`session` 基于签名 Cookie，敏感数据请存服务端（如 Redis）。

## 六、最佳实践

- 用 `get_json(silent=True)` 容错解析 JSON。
- 大文件上传设 `MAX_CONTENT_LENGTH` 限制。
- 不要在 `session` 里放大对象，仅放用户 ID 等小标识。
