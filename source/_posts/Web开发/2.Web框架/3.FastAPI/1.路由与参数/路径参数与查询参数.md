## 一、最小应用

```python
from fastapi import FastAPI
app = FastAPI()

@app.get('/')
def root():
    return {'msg': 'hello'}
```

`uvicorn main:app --reload` 启动，自动生成交互式文档 `/docs`、`/redoc`。

## 二、路径参数

```python
@app.get('/items/{item_id}')
def read_item(item_id: int):
    return {'item_id': item_id}
```

FastAPI 会**自动做类型校验与转换**：传入非 int 直接返回 422。支持 `int`/`float`/`str`/`bool`/`enum` 等。

## 三、查询参数

```python
@app.get('/items/')
def list_items(skip: int = 0, limit: int = 10, q: str | None = None):
    return {'skip': skip, 'limit': limit, 'q': q}
```

函数参数既非路径参数、又非声明为 `Body`，则视为查询参数；`= None` 或 `Optional` 表示可选。

## 四、参数校验（Query/Path）

```python
from fastapi import Query, Path

@app.get('/items/')
def list_items(q: str = Query(default=None, min_length=3, max_length=50)):
    ...

@app.get('/items/{item_id}')
def read_item(item_id: int = Path(..., gt=0)):
    ...
```

`Query`/`Path` 支持 `alias`、`deprecated`、`regex`、`ge/le` 等约束。

## 五、多路由与顺序

```python
@app.get('/users/me')        # 必须放在 /users/{id} 之前
def me(): ...
@app.get('/users/{user_id}')
def user(user_id: int): ...
```

路径声明顺序影响匹配，更具体的规则放前面。

## 六、最佳实践

- 充分利用类型注解：既是文档、又是校验、又是编辑器提示。
- 用 `Query`/`Path`/`Header`/`Cookie` 显式声明校验，可读性更好。
- 路径参数用 `Path(..., gt=0)` 表示必填且约束。
- 善用 `/docs` 联调，开发效率极高。
