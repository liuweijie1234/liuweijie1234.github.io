## 一、依赖注入是什么

`Depends` 让 FastAPI 在调用路径函数前**自动执行依赖函数、注入其结果**，用于共享逻辑（鉴权、DB 会话、公共参数）。

```python
from fastapi import Depends

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

@app.get('/users/')
def users(db: Session = Depends(get_db)):
    return db.query(User).all()
```

## 二、依赖可嵌套

依赖自身也能依赖别的依赖，FastAPI 负责按图解析、缓存与复用。

```python
def get_current_user(token: str = Depends(oauth2)):
    return decode(token)

@app.get('/me')
def me(user = Depends(get_current_user)):
    return user
```

## 三、类作为依赖

依赖可以是类，`Depends(Class)` 会调用其 `__init__`：

```python
class CommonParams:
    def __init__(self, q: str | None = None, skip: int = 0, limit: int = 100):
        self.q, self.skip, self.limit = q, skip, limit

@app.get('/items/')
def items(commons: CommonParams = Depends(CommonParams)):
    return commons
```

## 四、用依赖做鉴权（推荐）

把「取当前用户」写成子依赖，多处复用：

```python
@app.get('/admin')
def admin(user = Depends(get_current_active_user)):
    return user
```

配合 `Security` 与 `OAuth2`/`JWT`（见 `5.安全与认证`）更标准。

## 五、yield 依赖与资源释放

用 `yield` 的依赖在响应后执行 `finally` 段，适合 DB 连接、锁、事务提交：

```python
def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

## 六、最佳实践

- 把鉴权、DB、分页等横切逻辑抽成依赖，路径函数保持干净。
- 依赖可测试：直接调用依赖函数即可单测。
- 用 `yield` 依赖管理资源生命周期，确保释放。
