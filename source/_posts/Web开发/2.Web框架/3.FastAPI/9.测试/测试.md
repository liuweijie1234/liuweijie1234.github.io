## 一、TestClient

FastAPI 提供 `starlette.testclient.TestClient`（基于 `httpx`/`requests`）同步调用 ASGI 应用：

```python
from fastapi.testclient import TestClient
from main import app

client = TestClient(app)

def test_read_root():
    r = client.get('/')
    assert r.status_code == 200
    assert r.json()['msg'] == 'hello'
```

## 二、pytest 写法

```python
def test_create_item():
    r = client.post('/items/', json={'name': 'a', 'price': 1.0})
    assert r.status_code == 200
    assert r.json()['name'] == 'a'
```

`json=` 自动序列化并设置 `Content-Type: application/json`。

## 三、覆盖依赖（override_dependencies）

测试时替换真实依赖（如数据库、鉴权）：

```python
from fastapi.testclient import TestClient

app.dependency_overrides[get_db] = override_get_db
client = TestClient(app)

def teardown():
    app.dependency_overrides.clear()
```

## 四、异步测试

需要 `httpx.ASGITransport` + `pytest-asyncio`：

```python
import pytest
from httpx import ASGITransport, AsyncClient

@pytest.mark.asyncio
async def test_async():
    transport = ASGITransport(app=app)
    async with AsyncClient(transport=transport, base_url='http://test') as c:
        r = await c.get('/')
        assert r.status_code == 200
```

## 五、认证/数据库测试

- 数据库：用测试库 + `pytest fixture` 建表/清表。
- 鉴权：用 `dependency_overrides` 注入假用户，避免真实登录。

## 六、最佳实践

- 每个接口至少覆盖：正常、校验失败（422）、权限（401/403）。
- 用 `dependency_overrides` 隔离外部依赖，测试快且稳定。
- 接入 CI，配合覆盖率门槛。
