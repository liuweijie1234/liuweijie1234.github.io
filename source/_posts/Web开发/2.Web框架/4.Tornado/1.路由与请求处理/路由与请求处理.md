## 一、Tornado 定位

Tornado 是 **异步非阻塞** Web 框架与网络库，适合长连接、高并发（WebSocket、长轮询）场景。它不是 WSGI 框架，运行在自家 IOLoop 上。

## 二、最小应用

```python
import tornado.ioloop
import tornado.web

class MainHandler(tornado.web.RequestHandler):
    def get(self):
        self.write({'msg': 'hello'})

def make_app():
    return tornado.web.Application([
        (r'/', MainHandler),
        (r'/user/([0-9]+)', UserHandler),
    ])

if __name__ == '__main__':
    app = make_app()
    app.listen(8888)
    tornado.ioloop.IOLoop.current().start()
```

## 三、路由与捕获

```python
class UserHandler(tornado.web.RequestHandler):
    def get(self, user_id):
        self.write({'user_id': user_id})
```

路由用正则捕获组，按顺序传给 `get(self, *args)`。

## 四、请求处理常用 API

| 方法/属性 | 作用 |
|-----------|------|
| `self.get_argument('x')` | 取参数（query 或 form） |
| `self.request.body` | 原始请求体 |
| `self.request.headers` | 请求头 |
| `self.write(obj)` | 写 JSON/文本 |
| `self.set_status(201)` | 状态码 |
| `self.set_header('X', 'v')` | 响应头 |
| `self.redirect('/')` | 跳转 |
| `self.render('t.html', **kw)` | 渲染模板 |

## 五、方法分发

`RequestHandler` 按 HTTP 方法找 `get/post/put/delete`；未实现的方法返回 405。用 `prepare()` 做统一预处理，`on_finish()` 做后置清理。

## 六、最佳实践

- 写阻塞操作时用 `@tornado.web.asynchronous` + 回调，或直接 `async`（见 `2.异步IO与协程`）。
- 路由规则集中放在 `Application` 的 `handlers` 列表。
- 不要在 handler 里做长耗时同步调用，会阻塞整个 IOLoop。
