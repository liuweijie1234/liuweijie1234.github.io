## 一、模板引擎

Tornado 自带模板系统，语法类似其他引擎，但更紧凑，且天然防 XSS（默认转义）。

## 二、渲染模板

```python
class MainHandler(tornado.web.RequestHandler):
    def get(self):
        self.render('index.html', title='首页', items=[1, 2, 3])
```

模板目录在 `Application(template_path='templates')` 指定。

## 三、语法

{% raw %}
```html
<h1>{{ title }}</h1>
<ul>
{% for i in items %}
  <li>{{ i }}</li>
{% end %}
</ul>

{% if user %}
  <p>{{ user }}</p>
{% else %}
  <p>游客</p>
{% end %}
```
{% endraw %}

控制语句以 `{% %}` 包裹，块结束用 `{% end %}`（不是 `{% endblock %}`）。

## 四、模板继承

{% raw %}
```html
<!-- base.html -->
<html><body>{% block body %}{% end %}</body></html>

<!-- index.html -->
{% extends "base.html" %}
{% block body %}<h1>首页</h1>{% end %}
```
{% endraw %}

## 五、UI 模块

```python
class Entry(tornado.web.UIModule):
    def render(self, entry):
        return f'<div>{entry}</div>'

app = Application(..., ui_modules={'Entry': Entry})
```

模板中：`{% module Entry(entry) %}`。

## 六、最佳实践

{% raw %}
- 模板默认转义，输出可信 HTML 时用 `&#123;% raw %&#125;`（慎用）。
- 逻辑前置到 handler，模板只展示。
- 用 `{% extends %}` + `{% block %}` 复用布局。
{% endraw %}
