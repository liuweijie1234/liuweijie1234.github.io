## 一、单进程启动

```python
app.listen(8888)
tornado.ioloop.IOLoop.current().start()
```

但单进程只用到一个 CPU，需多进程吃满多核。

## 二、多进程（fork）

```python
import tornado.httpserver

if __name__ == '__main__':
    app = make_app()
    server = tornado.httpserver.HTTPServer(app)
    server.bind(8888)
    server.start(0)          # 0 = 按 CPU 数 fork
    tornado.ioloop.IOLoop.current().start()
```

`server.start(0)` fork 出多个进程，共享端口。注意：fork 后各进程独立，不能用共享内存状态。

## 三、反向代理（Nginx）

```nginx
upstream tornado {
    server 127.0.0.1:8888;
    server 127.0.0.1:8889;
}
server {
    location / {
        proxy_pass http://tornado;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;     # WebSocket 必须
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}
```

WebSocket 需要 `Upgrade`/`Connection` 头透传。

## 四、HTTPS 与静态

- HTTPS 由 Nginx 终结，Tornado 跑 HTTP。
- 静态文件用 `static_path` + `StaticFileHandler`，生产建议 Nginx 直出。

## 五、最佳实践

- 用多进程 + Nginx 反代；WebSocket 注意 Upgrade 头。
- 长连接场景调大 `max_body_sizes`、`idle_timeout`。
- 进程崩溃用 supervisor/systemd 守护；平滑重启用 `SIGTERM` + 重新 fork。
- 与 Gunicorn 的 `tornado` worker 也可：`gunicorn -k tornado app:app`。
