# Web 开发学习路线

本目录整理 Python Web 开发的主流知识地图：从**底层协议与基础概念**，到**主流框架（Django / Flask / FastAPI / Tornado）**，再到**异步任务、基础设施与扩展、RESTful API**。

> 阅读建议：先打牢「基础与协议」，再按需求深入某一框架，最后补齐异步任务、部署与周边。所有文件夹已按学习顺序编号。

## 目录结构

```
Web开发/
├── 1.基础与协议/        # 协议、架构、设计模式、认证授权（地基）
├── 2.Web框架/           # Django / Flask / FastAPI / Tornado（主力）
├── 3.异步任务与消息队列/ # Celery（分布式任务）
├── 4.基础设施与扩展/     # 中间件 / 高并发 / 邮件 / 直播
└── 5.RESTfulAPI/        # API 设计规范与最佳实践
```

## 一、基础与协议（1.基础与协议）

地基不牢，框架白学。建议顺序：

1. **请求与响应**：`GET和POST区别`、`TCP三次握手四次挥手`、`http和https`、`http状态码`、`websocket`、`cookie与session`、`请求头详解`
2. **开发模式**：`MVC`、`MTV`、`MVVM`
3. **架构**：`分层架构`、`微服务简介`
4. **设计模式**：`单例`、`工厂`、`接口`、`观察者`、`装饰器模式`、`代理模式`、`策略模式`
5. **认证与权限**：`APIKey`、`JWT`、`Session-Cookie认证`、`OAuth2概览`

## 二、Web 框架（2.Web框架）

| 框架 | 定位 | 必学主线 |
|------|------|----------|
| **Django** | 全栈、开箱即用 | 路由→视图→模板/表单→ORM→Admin→安全→缓存→部署 |
| **Flask** | 轻量、灵活 | 路由→蓝图→模板→请求响应→WTForms→SQLAlchemy→扩展→部署 |
| **FastAPI** | 异步、类型、API 首选 | 参数→Pydantic→响应模型→依赖注入→认证→中间件→异步→测试→部署 |
| **Tornado** | 异步、长连接、WebSocket | 路由→异步协程→WebSocket→模板→部署 |

每个框架目录内均按 `0.入门 / 1.模型与ORM / 2.路由与视图 / ...` 编号，循序渐进。

## 三、异步任务与消息队列（3.异步任务与消息队列）

- **Celery**：`1.基本知识` → `2.概念`(Broker/Worker/Task) → `3.配置参数` → `4.高阶用法`(重试/多队列/多Worker) → `5.实战`(部署/伸缩/容错) → `6.其他`，另含面试题。

## 四、基础设施与扩展（4.基础设施与扩展）

- **中间件**：`elasticsearch`、`pika`(RabbitMQ 客户端)
- **高并发**：`限流/slowapi`
- **邮件**：`email`、`smtplib`、`poplib`
- **直播**：`原理`、`推流和拉流`、`ffmpeg`、`nginx-rtmp`、`video.js`、`秒开`、`延迟和卡顿`

## 五、RESTful API（5.RESTfulAPI）

- `RESTfulAPI`(概览)、`设计原则`、`状态码与版本控制`、`最佳实践`

## 推荐学习路径

```
基础协议 ──► 选一个框架深入（建议 Django 或 FastAPI）
   │              │
   │              ├──► RESTfulAPI 设计
   │              ├──► Celery 异步任务
   │              └──► 部署（Nginx + Gunicorn/uWSGI）
   └──► 架构/设计模式/认证授权（贯穿始终）
```
