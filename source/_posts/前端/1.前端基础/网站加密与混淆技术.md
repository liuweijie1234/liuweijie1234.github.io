# JavaScript 网站加密和混淆技术

在爬虫、安全分析或保护前端代码时，常涉及 JS 加密、混淆与逆向调试。本文整理入门资料与常用手法。

## 1. 简介

前端代码运行在用户浏览器中，天然「可见」，因此常通过压缩、混淆、加密来提升逆向成本，或在请求参数中加入加密签名（如风控、反爬）。

- [JavaScript 网站加密和混淆技术简介](https://cuiqingcai.com/2022111.html)

## 2. 常见混淆手段

- **变量/函数名混淆**：有意义命名 → 无意义短名（`a`、`_0x12ab`）。
- **控制流扁平化**：把顺序逻辑拆成 `switch/while` 调度器，增加阅读难度。
- **字符串加密**：字符串常量加密，运行时解密（配合 `eval` / `Function`）。
- **反调试**：检测 `debugger`、对 `toString` 做校验、定时卡死开发者工具。

## 3. 逆向调试技巧

- [JavaScript 逆向调试常用技巧](https://cuiqingcai.com/2022112.html)

常用手段：

- 浏览器 Sources 面板断点、条件断点、XHR/fetch 断点。
- 搜索关键字（参数名、加密函数名、`eval`、`atob`、`encrypt`）。
- 借助 `Proxy` 或重写全局对象方法（如 `JSON.parse`）插桩输出。

## 4. Hook 的用法

- [JavaScript Hook 的用法](https://cuiqingcai.com/2022113.html)

Hook 即在目标方法执行前后注入自定义逻辑，用于捕获参数/返回值。示例：

```js
// Hook JSON.stringify，观察被加密的原始数据
(function () {
  const _stringify = JSON.stringify
  JSON.stringify = function (...args) {
    console.log('JSON.stringify 调用，参数：', args[0])
    return _stringify.apply(this, args)
  }
})()
```
