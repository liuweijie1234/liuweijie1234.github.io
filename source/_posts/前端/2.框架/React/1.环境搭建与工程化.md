# React 环境搭建与工程化

React 推荐用 Vite 快速搭建工程，配合 TypeScript、ESLint 形成现代开发链路。

## 1. 创建项目（Vite）

```bash
npm create vite@latest my-react-app -- --template react-ts
cd my-react-app
npm install
npm run dev
```

> 旧版 `create-react-app`（CRA）已不再积极维护，官方推荐 Vite / Next.js。

## 2. 项目结构

```text
src/
├── main.tsx          # 入口，挂载 <App/>
├── App.tsx           # 根组件
├── components/       # 业务组件
├── hooks/            # 自定义 Hooks
├── store/            # 状态管理（Redux/Zustand）
├── router.tsx        # 路由（React Router）
└── utils/            # 工具（axios 封装等）
```

```tsx
// main.tsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App'

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
)
```

## 3. 多环境与代理

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
export default defineConfig({
  plugins: [react()],
  server: {
    proxy: { '/api': { target: 'http://localhost:3000', changeOrigin: true } }
  }
})
```

## 4. TSX 与 JSX

React 使用 JSX（或 TSX）在 JS 中书写 UI，Babel/SWC 编译为 `React.createElement` 调用。

```tsx
const el = <h1 className="title">Hello</h1>
// 编译后 ≈ React.createElement('h1', { className: 'title' }, 'Hello')
```

## 5. 与 Vue3 工程化对比

| 维度 | Vue3（create-vue） | React（Vite react-ts） |
| --- | --- | --- |
| 模板 | SFC `.vue` | JSX/TSX |
| 状态 | `ref`/`reactive` 自动追踪 | `useState` 显式触发 |
| 脚手架选项 | Router/Pinia/Vitest 内置勾选 | 需自行接入 Router/状态库 |
