# JSX 与组件

React 以组件为单位组织 UI，当前主流为**函数组件**（配合 Hooks）。

## 1. 函数组件

```tsx
function Welcome({ name }: { name: string }) {
  return <h1>Hello, {name}</h1>
}
```

`<script setup>` 对比 Vue3：Vue 模板与逻辑分离在 `.vue`，React 直接在 `.tsx` 中返回 JSX。

## 2. JSX 语法要点

- **表达式**：`{ }` 包裹 JS 表达式（变量、函数调用、三元等）。
- **属性**：`className` 代替 `class`，`htmlFor` 代替 `for`，`style={{ color: 'red' }}` 用对象。
- **列表渲染**：`array.map`，必须给每项稳定的 `key`。

```tsx
const list = ['a', 'b', 'c']
<ul>
  {list.map((item, i) => <li key={i}>{item}</li>)}
</ul>
```

> `key` 帮助 React 识别节点，避免使用数组索引作为 key（列表重排时易出错，除非静态列表）。

- **条件渲染**：`{ ok ? <A /> : <B />}` 或 `&&`：`{ ok && <A /> }`。

## 3. 事件与表单

```tsx
function Form() {
  const [val, setVal] = useState('')
  return (
    <input
      value={val}
      onChange={(e) => setVal(e.target.value)}  // 受控组件
    />
  )
}
```

> React 事件用 camelCase（`onClick`），Vue 用 `@click`；React 受控组件通过 `value` + `onChange` 绑定。

## 4. 组件复用：props 与 children

```tsx
function Card({ title, children }: { title: string; children: React.ReactNode }) {
  return (
    <div className="card">
      <h3>{title}</h3>
      <div>{children}</div>
    </div>
  )
}
// 使用：<Card title="标题">内容</Card>
```

## 5. Context 跨层传值

```tsx
const ThemeContext = React.createContext('light')
function App() {
  return (
    <ThemeContext.Provider value="dark">
      <Child />
    </ThemeContext.Provider>
  )
}
function Child() {
  const theme = React.useContext(ThemeContext)
  return <div>当前主题：{theme}</div>
}
```
