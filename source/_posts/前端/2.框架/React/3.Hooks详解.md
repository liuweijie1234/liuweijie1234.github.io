# React Hooks 详解

Hooks 让函数组件拥有状态与生命周期能力。规则：**只在函数顶层调用，不在条件/循环中使用**。

## 1. useState

```tsx
const [count, setCount] = useState(0)
// 更新：setCount(count + 1) 或 setCount(c => c + 1)
```

> 对应 Vue3 的 `ref`/`reactive`。

## 2. useEffect（副作用）

```tsx
useEffect(() => {
  const id = setInterval(() => {}, 1000)
  return () => clearInterval(id)   // 清理函数
}, [])                            // 依赖为空：仅挂载/卸载执行
```

- 依赖数组 `[]`：只跑一次（类似 `onMounted`）。
- 依赖 `[a]`：a 变化时执行。
- 无依赖：每次渲染后都执行。

> 注意依赖遗漏会导致闭包拿到旧值；可用 `eslint-plugin-react-hooks` 校验。

## 3. useMemo / useCallback（性能优化）

```tsx
const expensive = useMemo(() => heavyCalc(list), [list])
const handle = useCallback((id: number) => {...}, [])
```

- `useMemo`：缓存计算结果（类似 Vue `computed`）。
- `useCallback`：缓存函数引用，避免子组件无谓重渲染。

## 4. useRef

```tsx
const inputRef = useRef<HTMLInputElement>(null)
useEffect(() => inputRef.current?.focus(), [])
<input ref={inputRef} />
```

> `useRef` 值变更不触发重渲染，适合存 DOM 引用或可变实例。

## 5. 自定义 Hook

```tsx
// hooks/useToggle.ts
import { useState } from 'react'
export function useToggle(init = false) {
  const [on, setOn] = useState(init)
  const toggle = () => setOn(v => !v)
  return [on, toggle] as const
}
```

## 6. Vue3 对照

| React | Vue3 |
| --- | --- |
| `useState` | `ref` / `reactive` |
| `useEffect` | `onMounted`/`watch`/`watchEffect` |
| `useMemo` | `computed` |
| `useRef` | `ref` (DOM) |
