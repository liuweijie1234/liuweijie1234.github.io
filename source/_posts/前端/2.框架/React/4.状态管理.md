# React 状态管理

React 状态分为：组件内 `useState`、跨层 `Context`、以及全局状态库（Redux / Zustand 等）。

## 1. 轻量方案：Context + useReducer

适合中小规模共享状态（如主题、用户态）。

```tsx
const reducer = (state: State, action: Action) => { /* ... */ }
const [state, dispatch] = useReducer(reducer, initialState)
```

> 频繁更新的大状态不建议用 Context（易引发大范围重渲染），改用状态库。

## 2. Zustand（推荐，简洁）

```bash
npm install zustand
```

```tsx
// store/user.ts
import { create } from 'zustand'
export const useUserStore = create((set) => ({
  name: '',
  token: '',
  login: (t: string, n: string) => set({ token: t, name: n }),
  logout: () => set({ token: '' })
}))

// 组件
const name = useUserStore((s) => s.name)
const login = useUserStore((s) => s.login)
```

> 比 Redux 样板代码少很多，TypeScript 友好，类似 Vue 的 Pinia。

## 3. Redux Toolkit（企业级）

```bash
npm install @reduxjs/toolkit react-redux
```

```tsx
import { createSlice, configureStore } from '@reduxjs/toolkit'
const user = createSlice({
  name: 'user',
  initialState: { name: '' },
  reducers: {
    setUser: (state, action) => { state.name = action.payload }
  }
})
export const store = configureStore({ reducer: { user: user.reducer } })
```

```tsx
import { Provider, useSelector, useDispatch } from 'react-redux'
// <Provider store={store}><App/></Provider>
const name = useSelector((s) => s.user.name)
const dispatch = useDispatch()
```

## 4. 方案选择

| 方案 | 适用 |
| --- | --- |
| `useState` + `props` | 父子局部状态 |
| Context | 低频跨层共享（主题/语言） |
| Zustand | 中小型应用、快速开发 |
| Redux Toolkit | 大型团队协作、需时间旅行调试 |
