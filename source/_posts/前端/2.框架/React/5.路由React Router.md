# React Router（v6）

React Router 是 React 生态最主流的路由库，v6 采用 `<Routes>` / `<Route>` 声明式配置，API 更简洁。

## 1. 安装与配置

```bash
npm install react-router-dom
```

```tsx
// router.tsx
import { createBrowserRouter, RouterProvider } from 'react-router-dom'
import Layout from './Layout'
import Home from './pages/Home'

const router = createBrowserRouter([
  {
    path: '/',
    element: <Layout />,
    children: [
      { index: true, element: <Home /> },
      { path: 'user/:id', element: <User />, loader: userLoader }
    ]
  }
])

export default function App() {
  return <RouterProvider router={router} />
}
```

## 2. 导航与参数

```tsx
import { useNavigate, useParams, useLocation, Link } from 'react-router-dom'

function User() {
  const { id } = useParams()         // 取 :id
  const navigate = useNavigate()
  const goHome = () => navigate('/')
  return (
    <>
      <Link to="/">首页</Link>
      <button onClick={goHome}>返回</button>
    </>
  )
}
```

> `useNavigate` 对应 Vue 的 `useRouter().push`；`useParams` 对应 `route.params`。

## 3. 路由守卫（鉴权）

v6 推荐用 `loader` 或 wrapper 组件实现守卫：

```tsx
function RequireAuth({ children }: { children: JSX.Element }) {
  const token = localStorage.getItem('token')
  if (!token) return <Navigate to="/login" replace />
  return children
}

// 路由配置中包裹
{ path: 'admin', element: <RequireAuth><Admin /></RequireAuth> }
```

也可在 `loader` 中做权限预检并 `redirect`。

## 4. 嵌套路由与布局

```tsx
// Layout.tsx
import { Outlet } from 'react-router-dom'
export default function Layout() {
  return (
    <div>
      <nav>侧边栏</nav>
      <Outlet />   {/* 子路由渲染出口，类似 Vue 的 <router-view> */}
    </div>
  )
}
```

## 5. 与 Vue Router 对照

| React Router v6 | Vue Router |
| --- | --- |
| `<Outlet/>` | `<router-view/>` |
| `useNavigate()` | `useRouter().push()` |
| `useParams()` | `route.params` |
| `Navigate` 组件 | `router.replace` |
