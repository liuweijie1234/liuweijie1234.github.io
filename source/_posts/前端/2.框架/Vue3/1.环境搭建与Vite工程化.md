# 环境搭建与 Vite 工程化

本文整合 Vue 项目初始化命令，并重点介绍 Vue3 推荐工程化方案：基于 Vite 的 create-vue 脚手架。

## 1. 创建项目

### 使用 create-vue（官方推荐，Vue3）

```bash
npm init vue@latest     # 最新 Vue 版本（官方当前最新）
# 等价于
npx create-vue@latest

npm init vue@next       # 下一个版本
npx create-vue@next

npm init vue@3.7.3      # 直接指定版本
```

### 使用 create-vite

```bash
npm create vite@latest
# 等价于
npm init vite@latest
```

> `npm create vite` 与 `npm init vue` 区别：前者是通用前端构建脚手架（可选 vue 模板），后者是 Vue 官方定制脚手架，默认集成 Router/Pinia/ESLint/Vitest 等选项，更适合 Vue 工程。

### 使用 vue-cli（旧，Vue2 时代，逐步淘汰）

```bash
npm install -g @vue/cli   # 需 4.5.0+
vue create <project-name>
cd <project-name> && npm run serve
```

## 2. 初始化与运行

```bash
cd vue_test/
npm install        # 安装依赖
npm run dev        # 启动开发服务器
```

安装常用依赖：

```bash
npm install --save axios vue-axios
```

## 3. Vite 工程化要点

- **极速冷启动**：基于原生 ES 模块（ESM），无需打包整个应用。
- **HMR**：模块级热更新，毫秒级反馈。
- **构建**：`npm run build` 走 Rollup，产出优化后的静态资源。
- **多环境**：通过 `.env` / `.env.development` / `.env.production` 与 `import.meta.env` 读取环境变量。
- **配置代理**（解决开发跨域）：

```ts
// vite.config.ts
import { defineConfig } from 'vite'
export default defineConfig({
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:3000',
        changeOrigin: true,
        rewrite: (p) => p.replace(/^\/api/, '')
      }
    }
  }
})
```
