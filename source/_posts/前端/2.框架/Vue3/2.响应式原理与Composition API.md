# 响应式原理与 Composition API

Vue3 的响应式系统基于 ES6 `Proxy` 实现，组合式 API（Composition API）以函数方式组织逻辑，配合 `<script setup>` 语法糖大幅提升可维护性。

## 1. 响应式核心

### Vue2 vs Vue3

| | Vue2 | Vue3 |
| --- | --- | --- |
| 实现 | `Object.defineProperty` | `Proxy` |
| 数组/新增属性 | 需 `$set` | 原生支持 |
| 惰性依赖收集 | 否 | 是（用到才追踪） |

### 常用 API

- `ref`：包裹基本类型（或对象），通过 `.value` 访问；模板中自动解包。
- `reactive`：包裹对象/数组，直接访问属性即响应式。
- `computed`：派生状态，带缓存。
- `watch` / `watchEffect`：监听变化执行副作用。

```ts
import { ref, reactive, computed, watch } from 'vue'

const count = ref(0)
const state = reactive({ name: 'Tom', list: [] as number[] })
const double = computed(() => count.value * 2)

watch(count, (n, o) => console.log(`count ${o} -> ${n}`))
```

## 2. Proxy 响应式原理（简析）

Vue3 用 `Proxy` 拦截对象读写，配合 `effect`/`track`/`trigger` 完成依赖收集与派发更新：

```js
function reactive(obj) {
  return new Proxy(obj, {
    get(target, key, receiver) {
      track(target, key)              // 依赖收集
      return Reflect.get(target, key, receiver)
    },
    set(target, key, value, receiver) {
      const r = Reflect.set(target, key, value, receiver)
      trigger(target, key)            // 派发更新
      return r
    }
  })
}
```

> 模板渲染时读取响应式属性 → `track` 记录当前副作用（组件渲染函数）→ 属性变更时 `trigger` → 重新执行副作用。

## 3. Composition API 与 `<script setup>`

```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'

const msg = ref('Hello Vue3')
function change() { msg.value = 'Changed' }

onMounted(() => console.log('mounted'))
</script>

<template>
  <h1>{{ msg }}</h1>
  <button @click="change">改</button>
</template>
```

- `<script setup>` 中顶层绑定（变量、函数）自动暴露给模板，无需 `return`。
- 逻辑可抽成 composable（以 `useXxx` 命名、返回响应式状态的函数），实现跨组件复用。

## 4. 组合式函数（Composable）示例

```ts
// composables/useCounter.ts
import { ref } from 'vue'
export function useCounter(init = 0) {
  const count = ref(init)
  const inc = () => count.value++
  const dec = () => count.value--
  return { count, inc, dec }
}
```
