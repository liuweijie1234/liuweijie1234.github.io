# 路由 Vue Router 与路由守卫

Vue Router 是 Vue 官方路由，配合 Vue3 实现单页应用（SPA）的视图切换与权限控制。

## 1. 安装与基本配置

```bash
npm install vue-router@4
```

```ts
// router/index.ts
import { createRouter, createWebHistory } from 'vue-router'
import Home from '@/views/Home.vue'

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/', component: Home, name: 'home' },
    { path: '/user/:id', component: () => import('@/views/User.vue'), meta: { auth: true } }
  ]
})

export default router
```

```ts
// main.ts
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
createApp(App).use(router).mount('#app')
```

## 2. 路由视图与跳转

```vue
<template>
  <router-link to="/">首页</router-link>
  <router-view />
</template>

<script setup lang="ts">
import { useRouter, useRoute } from 'vue-router'
const router = useRouter()
const route = useRoute()
router.push({ name: 'home' })
console.log(route.params.id)
</script>
```

## 3. 路由守卫（权限控制核心）

### 全局前置守卫

```ts
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token')
  if (to.meta.auth && !token) {
    next({ path: '/login' })   // 未登录跳转登录
  } else {
    next()                     // 放行
  }
})
```

### 其他守卫

- `router.afterEach`：跳转后钩子（如页面标题、埋点）。
- 路由独享守卫：`beforeEnter`。
- 组件内守卫：`onBeforeRouteLeave` / `onBeforeRouteUpdate`（组合式）。

```ts
import { onBeforeRouteLeave } from 'vue-router'
onBeforeRouteLeave((to, from) => {
  return confirm('确定离开？未保存的修改将丢失')
})
```

## 4. 嵌套路由与懒加载

```ts
{
  path: '/admin',
  component: () => import('@/layouts/Admin.vue'),
  children: [
    { path: 'list', component: () => import('@/views/admin/List.vue') }
  ]
}
```

> 路由懒加载（`() => import()`）配合 Vite 自动代码分割，提升首屏速度。
