# 状态管理 Pinia

Pinia 是 Vue 官方推荐的状态管理库，替代 Vuex，API 更简洁、对 TypeScript 更友好。

## 1. 安装与定义 Store

```bash
npm install pinia
```

```ts
// main.ts
import { createPinia } from 'pinia'
createApp(App).use(createPinia()).mount('#app')
```

```ts
// stores/user.ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useUserStore = defineStore('user', () => {
  const token = ref('')
  const name = ref('')
  const isLogin = computed(() => !!token.value)

  function login(t: string, n: string) {
    token.value = t
    name.value = n
  }
  function logout() {
    token.value = ''
    name.value = ''
  }
  return { token, name, isLogin, login, logout }
})
```

> 也支持 Options 写法：`defineStore('user', { state, getters, actions })`。

## 2. 在组件中使用

```vue
<script setup lang="ts">
import { useUserStore } from '@/stores/user'
import { storeToRefs } from 'pinia'

const user = useUserStore()
const { name, isLogin } = storeToRefs(user)  // 解构保持响应式
user.login('abc', 'Tom')
</script>

<template>
  <p v-if="isLogin">欢迎 {{ name }}</p>
  <button @click="user.logout">退出</button>
</template>
```

## 3. Pinia vs Vuex

| 对比 | Vuex | Pinia |
| --- | --- | --- |
| mutations | 必须 | 已移除（直接改 state） |
| TypeScript | 繁琐 | 一等公民支持 |
| 体积 | 较大 | 更小 |

## 4. 持久化

常见方案：`pinia-plugin-persistedstate` 插件，将状态同步到 `localStorage`：

```ts
import piniaPluginPersistedstate from 'pinia-plugin-persistedstate'
const pinia = createPinia()
pinia.use(piniaPluginPersistedstate)
```

```ts
defineStore('user', () => { /* ... */ }, { persist: true })
```
