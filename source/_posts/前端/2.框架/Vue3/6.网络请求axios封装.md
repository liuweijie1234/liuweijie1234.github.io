# 网络请求 axios 封装

使用 `axios` 封装统一请求层：拦截器处理 token 注入、错误统一提示、响应数据解包，并结合 [Vue Router 守卫](4.路由Vue%20Router与路由守卫.md) 做登录失效跳转。

## 1. 安装

```bash
npm install axios
# 或配合 vue-axios
npm install axios vue-axios
```

## 2. 基础封装

```ts
// utils/request.ts
import axios, { type AxiosInstance, type AxiosResponse } from 'axios'
import { ElMessage } from 'element-plus'
import router from '@/router'

const service: AxiosInstance = axios.create({
  baseURL: import.meta.env.VITE_API_BASE || '/api',
  timeout: 10000
})

// 请求拦截：注入 token
service.interceptors.request.use((config) => {
  const token = localStorage.getItem('token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

// 响应拦截：解包 + 错误处理
service.interceptors.response.use(
  (res: AxiosResponse) => {
    const data = res.data
    if (data.code && data.code !== 0 && data.code !== 200) {
      ElMessage.error(data.msg || '请求失败')
      return Promise.reject(data)
    }
    return data.data ?? data
  },
  (error) => {
    if (error.response?.status === 401) {
      ElMessage.error('登录已失效，请重新登录')
      router.push('/login')
    } else {
      ElMessage.error(error.message)
    }
    return Promise.reject(error)
  }
)

export default service
```

## 3. 业务接口组织

```ts
// api/user.ts
import request from '@/utils/request'

export function login(p: { username: string; password: string }) {
  return request.post('/auth/login', p)
}

export function getUser(id: string) {
  return request.get(`/user/${id}`)
}
```

组件调用：

```ts
import { getUser } from '@/api/user'
const data = await getUser('1')
```

## 4. 关键技巧

- **取消重复请求**：用 `AbortController` 或 `CancelToken`（v0.22+ 推荐 `AbortController`）。
- **Loading 状态**：配合 `ref` + 请求计数，或请求拦截统一控制。
- **多环境 baseURL**：Vite 下用 `import.meta.env.VITE_API_BASE`，详见 [Vite 工程化](1.环境搭建与Vite工程化.md)。
- **错误处理**：统一 `ElMessage` 提示（Element Plus，见 [UI 库](../../UI库/Element%20Plus/readme.md)）。
