# Element Plus 安装与快速上手

Element Plus 是 Vue3 的桌面端组件库（原 Vue2 的 Element UI 继任者）。

官方文档：<https://element-plus.org/zh-CN/>

> 旧版 Element UI 适用于 Vue2（<https://element.eleme.cn/>），新项目请统一使用 Element Plus（Vue3）。

## 1. 安装

```bash
npm install element-plus
npm install @element-plus/icons-vue   # 图标库
```

## 2. 完整引入（快速上手）

```ts
// main.ts
import { createApp } from 'vue'
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import App from './App.vue'

const app = createApp(App)
app.use(ElementPlus)
app.mount('#app')
```

## 3. 第一个组件

```vue
<script setup lang="ts">
import { ElMessage } from 'element-plus'
const open = () => ElMessage.success('操作成功')
</script>

<template>
  <el-button type="primary" @click="open">按钮</el-button>
</template>
```

## 4. Vue2 → Vue3 写法变化（重点）

| 维度 | Element UI（Vue2） | Element Plus（Vue3） |
| --- | --- | --- |
| 弹窗显隐 | `:visible.sync="show"` | `v-model="show"` |
| 消息提示 | `this.$message.success()` | `import { ElMessage } from 'element-plus'` |
| 确认框 | `this.$confirm()` | `import { ElMessageBox } from 'element-plus'` |
| 加载 | `this.$loading()` | `import { ElLoading } from 'element-plus'` |
| 安装 | `Vue.use(ElementUI)` | `app.use(ElementPlus)` |

三元运算在模板中常见，如动态标题：`{{ isAdd ? '新增产品型号' : '修改产品' }}`。

> `:visible.sync` 的迁移说明可参考 [Vue :visible.sync 的作用](https://juejin.cn/post/7016174289858609160)。
