# Element Plus 表单 Form 与校验

`el-form` + `el-form-item` + `el-input` 是后台表单的核心组合，内置校验规则与中文错误提示。

## 1. 基础表单

```vue
<script setup lang="ts">
import { reactive, ref } from 'vue'
import type { FormInstance, FormRules } from 'element-plus'

const formRef = ref<FormInstance>()
const form = reactive({ name: '', age: '' })
const rules = reactive<FormRules>({
  name: [{ required: true, message: '请输入名称', trigger: 'blur' }],
  age: [
    { required: true, message: '请输入年龄', trigger: 'blur' },
    { type: 'number', message: '年龄必须为数字', trigger: 'blur' }
  ]
})

const submit = async () => {
  await formRef.value?.validate((valid) => {
    if (valid) console.log('提交', form)
  })
}
</script>

<template>
  <el-form ref="formRef" :model="form" :rules="rules" label-width="80px">
    <el-form-item label="名称" prop="name">
      <el-input v-model="form.name" />
    </el-form-item>
    <el-form-item label="年龄" prop="age">
      <el-input v-model.number="form.age" />
    </el-form-item>
    <el-button type="primary" @click="submit">提交</el-button>
  </el-form>
</template>
```

## 2. 常用校验规则

| 规则 | 说明 |
| --- | --- |
| `required` | 必填 |
| `type` | `string`/`number`/`email`/`url` 等 |
| `pattern` | 正则，如手机号 `/^1[3-9]\d{9}$/` |
| `min` / `max` | 长度或数值范围 |
| `validator` | 自定义校验函数 |
| `trigger` | `blur`（失焦）/ `change`（变更） |

### 自定义校验

```ts
const rules = {
  confirm: [
    {
      validator: (_r, value, cb) => {
        if (value !== form.password) cb(new Error('两次密码不一致'))
        else cb()
      },
      trigger: 'blur'
    }
  ]
}
```

## 3. 动态表单（数组项）

```vue
<el-form-item
  v-for="(item, i) in form.items"
  :key="i"
  :label="'项' + i"
  :prop="'items.' + i + '.name'"
  :rules="{ required: true, message: '必填' }"
>
  <el-input v-model="item.name" />
</el-form-item>
```

## 4. 常用输入组件

- `el-input`（文本/密码/textarea）
- `el-select` + `el-option`（下拉）
- `el-radio-group` / `el-checkbox-group`
- `el-date-picker`（日期）
- `el-upload`（文件上传）
