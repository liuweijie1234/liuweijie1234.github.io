# Element Plus 表格 Table 与分页

`el-table` + `el-table-column` 展示结构化数据，`el-pagination` 处理分页，是后台列表页标配。

## 1. 基础表格

```vue
<script setup lang="ts">
const tableData = [
  { date: '2026-07-30', name: 'Tom', addr: '北京' },
  { date: '2026-07-31', name: 'Jerry', addr: '上海' }
]
</script>

<template>
  <el-table :data="tableData" border style="width: 100%">
    <el-table-column prop="date" label="日期" width="180" />
    <el-table-column prop="name" label="姓名" />
    <el-table-column prop="addr" label="地址" />
  </el-table>
</template>
```

## 2. 带分页

```vue
<script setup lang="ts">
import { ref } from 'vue'
const total = ref(100)
const page = ref(1)
const size = ref(10)
const list = ref([])

async function load() {
  // 调用接口，传入 page.value / size.value
  // list.value = await fetchList({ page: page.value, size: size.value })
}
</script>

<template>
  <el-table :data="list" border>
    <el-table-column type="index" label="#" />
    <el-table-column prop="name" label="名称" />
  </el-table>

  <el-pagination
    v-model:current-page="page"
    v-model:page-size="size"
    :total="total"
    :page-sizes="[10, 20, 50]"
    layout="total, sizes, prev, pager, next"
    @current-change="load"
    @size-change="load"
  />
</template>
```

## 3. 常用增强

- **列操作**：`<el-table-column label="操作"><template #default="scope">...{{ scope.row }}...</template></el-table-column>`
- **多选**：`<el-table-column type="selection" />` + `@selection-change`
- **排序/筛选**：`sortable`、`:filters`
- **动态高度**：`height` 属性开启固定表头滚动
- **树形**：`row-key` + `:tree-props`

## 4. 与接口联调

分页参数建议与 [axios 封装](../../框架/Vue3/6.网络请求axios封装.md) 的接口层对接，注意 `v-model:current-page` 是 Vue3 双向绑定写法（Vue2 为 `:current-page` + `@current-change`）。
