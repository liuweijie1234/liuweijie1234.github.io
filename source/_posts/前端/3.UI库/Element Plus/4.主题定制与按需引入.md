# Element Plus 主题定制与按需引入

生产环境推荐「按需引入」以减小打包体积，并通过 SCSS 变量定制品牌主题色。

## 1. 按需引入（自动导入）

借助 `unplugin-auto-import` 与 `unplugin-vue-components`，无需手动 `import` 组件与 API。

```bash
npm install -D unplugin-auto-import unplugin-vue-components
```

```ts
// vite.config.ts
import AutoImport from 'unplugin-auto-import/vite'
import Components from 'unplugin-vue-components/vite'
import { ElementPlusResolver } from 'unplugin-vue-components/resolvers'

export default defineConfig({
  plugins: [
    AutoImport({ resolvers: [ElementPlusResolver()] }),
    Components({ resolvers: [ElementPlusResolver()] })
  ]
})
```

配置后，模板中直接用 `<el-button>`，API 如 `ElMessage` 也会自动导入。

## 2. 主题色定制（SCSS 变量）

```bash
npm install -D sass
```

```ts
// vite.config.ts
export default defineConfig({
  css: {
    preprocessorOptions: {
      scss: {
        additionalData: `@use "element-plus/theme-chalk/src/index" as *;`
      }
    }
  }
})
```

在入口样式中覆盖变量：

```scss
/* styles/element/index.scss */
@forward 'element-plus/theme-chalk/src/common/var.scss' with (
  $colors: (
    'primary': ('base': #2f54eb)
  )
);
```

并在 `vite.config.ts` 的 `ElementPlusResolver` 中启用：

```ts
ElementPlusResolver({ importStyle: 'sass' })
```

同时调整 `additionalData` 引入自定义 scss。

## 3. 暗黑模式

```ts
import 'element-plus/theme-chalk/dark/css-vars.css'
// 给 <html> 加 class="dark" 即可切换暗黑主题
document.documentElement.classList.toggle('dark')
```

## 4. 图标按需

```ts
// vite.config.ts components resolver 增加 IconsResolver
import { IconsResolver } from 'unplugin-vue-components/resolvers'
Components({ resolvers: [IconsResolver(), ElementPlusResolver()] })
```

```vue
<el-icon><Edit /></el-icon>
```
