# 前端技术知识体系

本专栏以「**框架（Vue3 / React）+ UI 库（Element Plus）**」为主线，并系统归整前端基础与项目实战经验，适合初中级前端工程化进阶与查漏补缺。

## 模块导航

- **框架**
  - [Vue3](框架/Vue3/readme.md)：响应式原理、Composition API、组件通信、Vue Router、Pinia、axios 封装
  - [React](框架/React/readme.md)：工程化、JSX 与组件、Hooks、状态管理、React Router
- **UI 库**
  - [Element Plus](UI库/Element%20Plus/readme.md)：Vue3 组件库，含 Form 校验、Table 分页、主题定制与按需引入
- **前端基础**
  - [前端基础](前端基础/readme.md)：JavaScript 核心、CSS、Node.js、npm 命令、WebSocket、网站加密混淆、jQuery
- **项目实战**
  - [韩进 new-freight 前端系统](项目实战/韩进new-freight.md)：Vite + pnpm 多环境项目的拉取、安装与运行

## 学习建议

1. 先打牢 [前端基础](前端基础/readme.md)（JS/CSS/工程化工具链）。
2. 选定主框架：Vue 系走 [Vue3](框架/Vue3/readme.md)，React 系走 [React](框架/React/readme.md)。
3. 业务开发中配合 [Element Plus](UI库/Element%20Plus/readme.md) 快速搭建中后台界面。
4. 通过 [项目实战](项目实战/韩进new-freight.md) 串联完整工作流。
