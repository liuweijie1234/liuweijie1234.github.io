## 分组导航

- **关系型数据库**：以二维表（行/列）组织数据，通过 SQL 操作，强调 ACID 事务与强一致性，支持复杂关联查询与约束（主键、外键、唯一索引）。适用于金融、订单、账务等强一致性业务。
- **文档型数据库**：以半结构化文档（BSON/JSON）为存储单元，schema 灵活、可嵌套，水平扩展能力强。适合内容管理、物联网、敏捷业务模型。
- **键值与缓存数据库**：以 Key-Value 形式存储，读写极快（常驻内存），多用于缓存、会话、计数器、排行榜、分布式锁、消息队列等场景。
