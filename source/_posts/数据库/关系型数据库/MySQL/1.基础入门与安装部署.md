# MySQL 基础入门与安装部署

> 本文面向「从零到能干活」的工程师：先建立关系型数据库与 MySQL 的整体认知，再落地安装、连接、基础 SQL、三范式与日期处理，最后给出常见报错排错。

---

## 1. 什么是关系型数据库 & 为什么选 MySQL

**关系型数据库（RDBMS）** 以二维表（行/列）组织数据，通过 SQL 操作，核心特征是：

- **表结构（Schema）**：列类型、约束（主键、外键、唯一、非空）预先定义；
- **ACID 事务**：保证并发下的数据一致性；
- **SQL 标准**：跨库可迁移的声明式查询语言；
- **强关联**：通过外键维护实体间关系。

**MySQL** 是流行的开源 RDBMS，凭借 InnoDB 存储引擎 + B+ 树索引 + MVCC 的组合，成为互联网 OLTP（联机事务处理）的首选。版本选型：

| 维度 | MySQL 5.7 | MySQL 8.0 |
| --- | --- | --- |
| 默认认证插件 | mysql_native_password | caching_sha2_password |
| 窗口函数 / CTE | 不支持 | 支持 |
| 原子 DDL | 不支持 | 支持 |
| 自增计数器持久化 | 重启可能回退 | 持久化 |
| 默认字符集 | latin1 / utf8 | utf8mb4 |
| 隐藏索引 / 降序索引 | 不支持 | 支持 |

> 新项目直接上 8.0；老项目若依赖 `utf8`（实为 3 字节）或特定驱动兼容，需评估后再升级。

## 2. 安装部署

### 2.1 Windows 安装

下载地址：<https://dev.mysql.com/downloads/mysql/>

安装后建议用 **DataGrip / SQLyog / Navicat Premium** 等 GUI 工具管理，其 SQL 编辑器体验远胜命令行。

### 2.2 macOS 安装（Homebrew）

```bash
# 安装
brew install mysql
brew install mysql@8.0

# 临时启动
mysql.server start

# 注册为后台服务（推荐）
brew services start mysql
brew services start mysql@8.0
```

首次安装后初始化安全配置：

```bash
mysql_secure_installation
```

按提示：设置 root 密码 → 移除匿名用户（Y）→ 禁止远程 root 登录（Y）→ 移除测试库（Y）→ 立即生效（Y）。

验证运行：

```bash
mysql -u root -p
brew services list | grep mysql
```

### 2.3 Docker 安装（推荐用于本地/测试环境）

```bash
docker run --name my-mysql \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=yourpassword \
  -d mysql:latest

# 进入容器验证
docker exec -it my-mysql mysql -u root -p
```

### 2.4 查看安装与数据目录

```sql
SELECT @@basedir;   -- 安装目录，如 C:\Program Files\MySQL\MySQL Server 5.7\
SELECT @@datadir;   -- 数据目录，如 C:\ProgramData\MySQL\MySQL Server 5.7\Data\
```

## 3. 连接与基础 SQL

### 3.1 连接管理

```sql
SHOW STATUS LIKE 'uptime';        -- 运行时长
SHOW STATUS LIKE 'Threads_connected';  -- 当前连接数
```

### 3.2 库与表（DDL / DML）

```sql
-- 创建库（指定字符集）
CREATE DATABASE `test`
  DEFAULT CHARSET utf8mb4
  COLLATE utf8mb4_general_ci;

SHOW DATABASES;
USE test;

-- 建表
CREATE TABLE `user` (
  `id`       BIGINT PRIMARY KEY AUTO_INCREMENT,
  `name`     VARCHAR(64) NOT NULL,
  `age`      TINYINT,
  `created`  DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY `uk_name` (`name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

SHOW TABLES;
DESC user;                 -- 查看表结构
SELECT * FROM user;
SELECT COUNT(*) FROM user;
```

### 3.3 增删改查

```sql
-- 批量插入
INSERT INTO user (name, age) VALUES
  ('John', 25), ('Jane', 30), ('Bob', 40);

-- 更新
UPDATE user SET age = 31 WHERE name = 'Jane';

-- 删除
DELETE FROM user WHERE name = 'Bob';

-- 删除表 / 截断
DROP TABLE IF EXISTS user;          -- 删结构与数据，立即释放空间
TRUNCATE TABLE user;                -- 只清数据、重置自增，保留结构
```

> `DELETE` 可回滚、`TRUNCATE` 不可回滚；带 `WHERE` 的 `DELETE` 不会立即释放磁盘空间，需 `OPTIMIZE TABLE` 或重建。

### 3.4 多表连接（JOIN）

```sql
-- LEFT JOIN：左表全保留，右表无匹配补 NULL
SELECT t1.c1, t2.c1
FROM t1 LEFT JOIN t2 ON t1.c1 = t2.c1;

-- RIGHT JOIN 与 LEFT JOIN 功能等价，仅表顺序相反
SELECT * FROM t1 RIGHT JOIN t2 ON t1.pk = t2.fk;

-- 分组 + 过滤
SELECT module, COUNT(*) FROM bugs GROUP BY module;
SELECT module, COUNT(*) FROM bugs GROUP BY module HAVING COUNT(*) > 10;
```

## 4. 数据库三范式（设计基石）

范式是「减少冗余、避免更新异常」的表设计准则：

1. **第一范式（1NF）**：字段原子不可再分，无重复列。
2. **第二范式（2NF）**：满足 1NF，且非主键列完全依赖主键（消除部分依赖，针对联合主键）。
3. **第三范式（3NF）**：满足 2NF，且非主键列不传递依赖主键（消除 `A→B→C` 的传递）。

> 实践中常做**反范式**（冗余字段、宽表）以换查询性能，尤其报表/数仓场景；范式与反范式需权衡。

## 5. 日期与时间处理

常用函数：

| 函数 | 作用 |
| --- | --- |
| `NOW()` | 当前日期时间 |
| `CURDATE()` / `CURTIME()` | 当前日期 / 时间 |
| `DATE_ADD(d, INTERVAL n DAY)` | 日期加间隔 |
| `DATE_SUB(d, INTERVAL n DAY)` | 日期减间隔 |
| `DATEDIFF(d1, d2)` | 相差天数 |
| `DATE_FORMAT(d, '%Y-%m-%d')` | 格式化 |
| `PERIOD_DIFF('202407','202406')` | 相差月份 |

```sql
-- 近 30 天
SELECT * FROM orders
WHERE DATE_SUB(CURDATE(), INTERVAL 30 DAY) <= DATE(created_at);

-- 本月第一天与最后一天
SELECT DATE_FORMAT(date_add(current_date, interval -day(current_date)+1 day), '%Y-%m-%d 00:00:00') AS firstday,
       CONCAT(last_day(current_date), ' 23:59:59') AS lastday;

-- 上个月数据
SELECT * FROM orders
WHERE PERIOD_DIFF(DATE_FORMAT(NOW(),'%Y%m'), DATE_FORMAT(created_at,'%Y%m')) = 1;

-- 每月统计（分组聚合）
SELECT DATE_FORMAT(create_time, '%Y-%m') AS mon, COUNT(*) AS cnt
FROM services_bluetooth
GROUP BY DATE_FORMAT(create_time,'%Y-%m')
ORDER BY mon DESC LIMIT 24;
```

> ⚠️ **不要在 `WHERE` 对列套函数**（如 `WHERE DATE(created)=...`），会导致索引失效。应改写为范围比较（见 `5.查询优化与执行计划`）。

## 6. 用户与权限管理

```sql
-- 查看用户
SELECT user, host FROM mysql.user;

-- 创建并授权
CREATE USER 'admin'@'%' IDENTIFIED BY '123456';
GRANT ALL PRIVILEGES ON *.* TO 'admin'@'%';
FLUSH PRIVILEGES;

-- MySQL 8.0 改密码
ALTER USER 'root'@'localhost' IDENTIFIED BY 'Ld@Qq123456';
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'Ld@Qq123456';

-- 回收/删除
REVOKE ALL PRIVILEGES ON *.* FROM 'admin'@'%';
DROP USER 'admin'@'%';
```

## 7. 常见报错排错

| 报错 | 原因 / 解决 |
| --- | --- |
| `Can't connect to local MySQL server` | 服务未启动：`brew services list \| grep mysql`；端口占用：`lsof -i :3306` |
| `ERROR 1045 Access denied` | 密码错误 / 无该 host 权限，检查 `mysql.user` |
| `Got a packet bigger than 'max_allowed_packet'` | 调大 `max_allowed_packet` |
| `initialize specified but the data directory has files` | 数据目录非空，清空后重试初始化 |
