# PostgreSQL 基础入门与安装部署

PostgreSQL（常称 Postgres）是功能最强大的开源**对象关系型数据库（ORDBMS）**，以标准兼容、扩展性强、稳定性高著称，被誉为「最像 Oracle 的开源数据库」。本文带你从零完成认知、安装、初始化与基础操作。

## 一、PostgreSQL 是什么

| 维度 | 说明 |
| --- | --- |
| 类型 | 对象关系型（ORDBMS），兼容 SQL 标准且支持面向对象特性 |
| 许可证 | PostgreSQL License（类 BSD，可自由商用，比 MySQL 的 GPL 更宽松） |
| 进程模型 | 每连接一个后端进程（非线程），稳定性高 |
| 扩展能力 | 自定义类型、函数、操作符、索引方法（GiST/GIN）、FDW 外部表 |
| 典型定位 | 复杂查询、地理空间（PostGIS）、JSON 文档、强一致性业务 |

> 与 MySQL 的「轻量易用」不同，Postgres 的强项是**复杂 SQL、严格标准、可扩展**。很多团队在需要「类 Oracle 能力又不想付费」时选它。

## 二、版本选择

- 版本号 `x.y`：`y` 是次要版本（如 16、17），每年一个大版本。
- 当前（2026）主流稳定版 **16 / 17**。建议用最新稳定版以获得性能与并行改进。
- 重要版本能力：10（声明式分区）、11（JIT、存储过程）、12（B-tree 去重、CTE 物化）、13（并行 vacuum、增量排序）、14（逻辑复制增强）、15（MERGE、压缩）、16（并行查询增强）。

## 三、安装部署

### 3.1 Linux（Ubuntu/Debian）

```bash
# Ubuntu 示例
sudo sh -c 'echo "deb http://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" > /etc/apt/sources.list.d/pgdg.list'
wget -qO- https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo apt-key add -
sudo apt-get update
sudo apt-get install -y postgresql-16

sudo systemctl start postgresql
sudo systemctl enable postgresql
```

### 3.2 macOS（Homebrew）

```bash
brew install postgresql@16
brew services start postgresql@16
```

### 3.3 Windows

官方提供交互式安装包 **EnterpriseDB (EDB) installer**，下载后按向导安装即可，自带 pgAdmin 图形工具。

### 3.4 Docker（推荐开发）

```bash
docker run -d \
  --name pg \
  -p 5432:5432 \
  -v ~/pg-data:/var/lib/postgresql/data \
  -e POSTGRES_USER=admin \
  -e POSTGRES_PASSWORD=secret \
  -e POSTGRES_DB=shop \
  postgres:16
```

## 四、核心角色与连接

Postgres 使用**角色（Role）** 体系，而非「用户/组」二分：

```bash
# 切换到默认超级用户 postgres
sudo -u postgres psql

# 创建角色（用户）与数据库
CREATE ROLE app WITH LOGIN PASSWORD 'app123';
CREATE DATABASE shop OWNER app;

# 赋权
GRANT ALL PRIVILEGES ON DATABASE shop TO app;
```

连接：

```bash
psql -h 127.0.0.1 -U app -d shop -p 5432
```

配置文件（数据目录内）：

| 文件 | 作用 |
| --- | --- |
| `postgresql.conf` | 主配置（内存、连接、WAL、日志等） |
| `pg_hba.conf` | 客户端认证（谁、从哪、用什么方式连） |
| `pg_ident.conf` | 操作系统用户到数据库角色的映射 |

```ini
# postgresql.conf 关键项
listen_addresses = 'localhost'   # 生产按需放开
shared_buffers = 4GB             # 通常设 RAM 的 25%
max_connections = 200
wal_level = replica              # 开启流复制所需
```

```ini
# pg_hba.conf 示例（末尾追加）
host    shop    app    192.168.1.0/24    scram-sha-256
```

修改后重载：`SELECT pg_reload_conf();` 或 `systemctl reload postgresql`。

## 五、基础操作（SQL）

```sql
-- 建表（带多种类型）
CREATE TABLE users (
  id        BIGSERIAL PRIMARY KEY,
  name      VARCHAR(50) NOT NULL,
  email     TEXT UNIQUE,
  age       SMALLINT CHECK (age >= 0),
  tags      TEXT[],
  profile   JSONB,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- 插入
INSERT INTO users (name, email, tags, profile)
VALUES ('张三', 'z@a.com', ARRAY['vip','dev'], '{"city":"北京"}');

-- 查询
SELECT id, name, tags[1] FROM users WHERE age > 18;

-- 更新 / 删除
UPDATE users SET age = 29 WHERE name = '张三';
DELETE FROM users WHERE id = 1;
```

## 七、常见安装排错

| 现象 | 原因 / 解决 |
| --- | --- |
| `role "postgres" does not exist` | 初始化未完成，用 `initdb` 或包管理器重新 init |
| `connection refused` | 服务未启动 / `listen_addresses` 未放开 / 防火墙 |
| `password authentication failed` | `pg_hba.conf` 认证方式或密码错误 |
| `FATAL: too many connections` | 调大 `max_connections` 或用连接池（PgBouncer） |
| 端口冲突 | 改 `postgresql.conf` 的 `port` |
