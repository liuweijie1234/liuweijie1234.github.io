# 1. 关系型数据库

以二维表（行/列）组织数据，通过 SQL 操作，强调 ACID 事务与强一致性，支持复杂关联查询与约束（主键、外键、唯一索引、CHECK）。适用于金融、订单、账务等强一致性业务。

## 本分组包含

- **MySQL**：最流行的开源关系型数据库。InnoDB 存储引擎 + B+ 树索引 + MVCC 的经典组合，是互联网公司的首选 OLTP 数据库。
- **PostgreSQL**：功能最强大的开源关系型数据库（对象关系型）。支持 JSONB、数组、范围类型、全文检索，以及 GIN/GiST/BRIN 等丰富索引，号称「最像 Oracle 的开源库」，适合复杂 query 与分析型混合负载。

> 两者对比与选型见 `PostgreSQL → 8.与 MySQL 对比选型`。
