# MongoDB 基础入门与安装部署

MongoDB 是当今最主流的**文档型（Document）数据库**，由 MongoDB Inc.（原 10gen）于 2009 年开源。它用 BSON（Binary JSON）格式存储文档，具备「灵活 Schema、水平扩展（分片）、高可用（复制集）」三大特征，是敏捷开发与海量半结构化数据的首选。

本文带你从零完成 MongoDB 认知、安装、部署与服务端配置，并穿插运维排错要点。

## 一、MongoDB 是什么

| 维度 | 说明 |
| --- | --- |
| 数据模型 | 文档（Document） = 一组键值对，类似 JSON 对象，嵌套数组/子文档 |
| 存储格式 | BSON（Binary JSON），二进制编码，支持更多数据类型（Date、BinData、ObjectId 等） |
| 集合（Collection） | 文档的逻辑分组，类比关系库的「表」，但**无强制列结构** |
| 数据库（Database） | 多个集合的物理容器 |
| 查询语言 | MQL（MongoDB Query Language），基于文档的声明式查询 |
| 事务 | 4.0+ 支持复制集单分片多文档事务，4.2+ 支持跨分片分布式事务 |

> 与关系库的核心差异：关系库「先建表、定列、定类型」，MongoDB「先写文档、字段随需而变」。这种**反范式、嵌套建模**能力，让对象到存储的映射（ODM）几乎是零成本。

## 二、版本与发行版选择

- **MongoDB Community Server**：开源免费，生产首选。
- **MongoDB Enterprise**：商业版，带审计、LDAP、加密等高级特性。
- **MongoDB Atlas**：官方全托管的云数据库（SaaS），免运维。
- **版本号语义**：`x.y.z`，`y` 为偶数（如 6.0、7.0、8.0）是**稳定版（Stable）**，`y` 为奇数（如 7.1、8.1）是**开发版（Development）**，生产环境永远选偶数大版本。

> 当前（2026）主流稳定版为 **7.0 / 8.0**。本文示例以 7.0 为准。

## 三、安装部署

### 3.1 Windows 安装

官方推荐使用 **MongoDB Compass**（官方 GUI）和 **DbGate** 等图形化工具进行可视化管理，开发体验最佳。

1. 下载安装包：访问 [MongoDB 中文手册：在 Windows 上安装](https://mongodb.net.cn/manual/tutorial/install-mongodb-on-windows/)。
2. 双击 `mongodb-windows-x86_64-7.0-signed.msi` 按向导安装（建议勾选「Install MongoDB as a Service」以服务方式常驻）。
3. 若安装过程提示**权限不足**，参考 [安装 MongoDB 提示权限不足的解决方法](https://blog.csdn.net/DIJIA_0000/article/details/111266675) —— 通常是用管理员身份运行安装包，或对目标目录赋予 `Everyone` 完全控制权限。

验证：

```powershell
mongod --version
mongo   # 7.0 起官方 shell 为 mongosh，老 mongo 已废弃
```

### 3.2 macOS 安装（Homebrew）

```bash
# 添加 tap 并安装
brew tap mongodb/brew
brew install mongodb-community@7.0

# 启动（后台服务）
brew services start mongodb-community@7.0

# 或前台临时运行
mongod --config /opt/homebrew/etc/mongod.conf
```

### 3.3 Linux（Ubuntu / CentOS）安装

```bash
# Ubuntu 示例
wget -qO - https://www.mongodb.org/static/pgp/server-7.0.asc | sudo apt-key add -
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
sudo apt-get update
sudo apt-get install -y mongodb-org
sudo systemctl start mongod
sudo systemctl enable mongod
```

### 3.4 Docker 部署（推荐开发/测试）

```bash
docker run -d \
  --name mongo \
  -p 27017:27017 \
  -v ~/mongo-data:/data/db \
  -e MONGO_INITDB_ROOT_USERNAME=admin \
  -e MONGO_INITDB_ROOT_PASSWORD=secret \
  mongo:7.0
```

进入容器交互：

```bash
docker exec -it mongo mongosh -u admin -p secret
```

## 四、核心配置 mongod.conf

MongoDB 通过 YAML 配置文件 `mongod.conf` 控制行为，关键段落：

```yaml
storage:
  dbPath: /data/db                 # 数据目录
  journal:
    enabled: true                  # 预写日志（WAL），保证崩溃恢复
systemLog:
  destination: file
  path: /var/log/mongodb/mongod.log
  logAppend: true
net:
  port: 27017
  bindIp: 127.0.0.1                # 生产务必限制绑定 IP，禁止 0.0.0.0 暴露公网
security:
  authorization: enabled           # 开启鉴权
replication:
  replSetName: rs0                 # 复制集名称（部署副本集时必填）
```

修改配置后重启生效：

```bash
sudo systemctl restart mongod
```

## 五、连接与基础操作

使用新版 `mongosh`（MongoDB Shell）：

```javascript
// 连接本地
mongosh

// 查看数据库
show dbs

// 切换/创建数据库（写入数据后才真正落盘）
use shop

// 插入一条文档
db.products.insertOne({
  name: "机械键盘",
  price: 399,
  tags: ["外设", "办公"],
  spec: { layout: "87键", switch: "茶轴" },
  createdAt: new Date()
})

// 查询
db.products.find({ price: { $gt: 100 } }).pretty()

// 创建用户
use admin
db.createUser({
  user: "app",
  pwd: "app123",
  roles: [{ role: "readWrite", db: "shop" }]
})
```

## 六、图形化管理工具

- **MongoDB Compass**：官方 GUI，支持可视化查询、聚合管道构建、索引分析、性能监控。新手强烈推荐。
- **DbGate**：开源多数据库管理工具，对 MongoDB 支持良好，可同时管理关系库。
- **Studio 3T**：商业 GUI，功能最全（SQL 到 MQL 转换、数据对比同步等）。
- **Navicat for MongoDB**：老牌商业工具。

## 七、目录与数据文件

MongoDB 数据目录（`dbPath`）下的核心文件：

| 文件/目录 | 作用 |
| --- | --- |
| `WiredTiger.wt` | WiredTiger 存储引擎主数据文件 |
| `WiredTiger.lock` | 防止多进程并发启动的锁文件 |
| `journal/` | 预写日志目录，崩溃恢复用 |
| `*.ns` | 命名空间（集合/索引）元数据 |
| `diagnostic.data/` | 诊断数据（FTDC），用于性能分析 |

## 八、常见安装排错

| 现象 | 原因与解决 |
| --- | --- |
| `error opening file: /data/db/mongod.lock` | 上次异常退出，删除 lock 文件后加 `--repair` 修复启动 |
| `Address already in use` | 27017 被占用，改 `net.port` 或杀掉旧进程 |
| Windows 权限不足 | 以管理员身份运行安装包，或给目标目录加 Everyone 完全控制 |
| 远程连接不上 | `bindIp` 未包含远程 IP；安全组/防火墙未放行 27017 |
| `mongosh: command not found` | 7.0 起官方 shell 为 `mongosh`，需单独安装，旧 `mongo` 已被废弃 |
