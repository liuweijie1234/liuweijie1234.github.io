# MongoDB CRUD 与聚合管道

MQL（MongoDB Query Language）基于文档而非 SQL，所有操作都围绕「集合中的文档」展开。本文系统讲解增删改查与强大的**聚合管道（Aggregation Pipeline）**，这是 MongoDB 数据分析的核心能力。

## 一、插入（Create）

```javascript
// 单条
db.users.insertOne({ name: "张三", age: 28, tags: ["a","b"] })

// 多条
db.users.insertMany([
  { name: "李四", age: 32 },
  { name: "王五", age: 25 }
])

// 未指定 _id 时驱动自动生成 ObjectId
```

`writeConcern` 控制写入安全级别（详见 7.事务与一致性）。

## 二、查询（Read）

### 基础查询

```javascript
db.users.find({ age: { $gt: 25 } })              // age > 25
db.users.find({ age: { $gte: 18, $lte: 30 } })   // 区间
db.users.find({ name: { $in: ["张三","李四"] } })
db.users.find({ tags: "a" })                      // 数组包含元素 a
db.users.find({ "addr.city": "北京" })            // 点号访问嵌套字段
db.users.findOne({ _id: ObjectId("...") })
```

### 投影（指定返回字段）

```javascript
db.users.find({ age: { $gt: 25 } }, { name: 1, age: 1, _id: 0 })
// 1 = 返回，0 = 不返回；_id 默认返回，需显式 0 排除
```

### 常用查询操作符

| 操作符 | 含义 |
| --- | --- |
| `$eq` / `$ne` | 等于 / 不等于 |
| `$gt` / `$gte` / `$lt` / `$lte` | 大小比较 |
| `$in` / `$nin` | 在/不在列表 |
| `$and` / `$or` / `$not` / `$nor` | 逻辑组合 |
| `$exists` | 字段是否存在 |
| `$type` | 按 BSON 类型匹配 |
| `$regex` | 正则匹配 |
| `$elemMatch` | 数组元素满足多个条件 |

```javascript
db.orders.find({
  $and: [
    { status: "PAID" },
    { items: { $elemMatch: { sku: "x", qty: { $gt: 1 } } } }
  ]
})
```

### 排序、分页、计数

```javascript
db.users.find().sort({ age: -1 }).skip(20).limit(10)  // 第 3 页，每页 10
db.users.countDocuments({ age: { $gt: 25 } })          // 精确计数
db.users.estimatedDocumentCount()                      // 估算计数（快）
```

> 深分页陷阱：`skip` 越大越慢（需扫描跳过）。大偏移用**游标分页**（按 `_id` 或时间游标）：`find({ _id: { $gt: lastId } }).limit(10)`。

## 三、更新（Update）

### 更新操作符（必须加 `$set` 等，否则整体替换）

```javascript
// 单条更新 age
db.users.updateOne(
  { name: "张三" },
  { $set: { age: 29 }, $inc: { loginCount: 1 } }
)

// 多条更新
db.users.updateMany(
  { age: { $lt: 18 } },
  { $set: { role: "minor" } }
)

// upsert：不存在则插入
db.users.updateOne(
  { name: "赵六" },
  { $set: { name: "赵六", age: 40 } },
  { upsert: true }
)
```

### 常用更新操作符

| 操作符 | 作用 |
| --- | --- |
| `$set` | 设置字段 |
| `$unset` | 删除字段 |
| `$inc` | 自增（原子计数） |
| `$push` / `$pull` | 数组追加 / 移除元素 |
| `$addToSet` | 数组追加（去重） |
| `$pop` | 弹出数组首尾 |
| `$rename` | 字段重命名 |

```javascript
db.users.updateOne(
  { name: "张三" },
  { $push: { tags: "vip" }, $inc: { score: 10 } }
)
```

> **原子性边界**：单文档内的所有字段更新是原子的；多文档需用事务（第 7 章）。

## 四、删除（Delete）

```javascript
db.users.deleteOne({ name: "张三" })
db.users.deleteMany({ age: { $lt: 18 } })
// db.users.drop()  // 删集合
```

## 五、聚合管道（Aggregation Pipeline）

聚合管道由**多个阶段（stage）** 组成，上一个阶段的输出作为下一个阶段的输入，类似 Unix 管道 `|`。

```javascript
db.orders.aggregate([
  { $match: { status: "PAID" } },          // 先过滤
  { $group: {                             // 再分组
      _id: "$userId",
      total: { $sum: "$amount" },
      cnt:  { $sum: 1 }
  }},
  { $sort: { total: -1 } },               // 排序
  { $limit: 10 }                          // 取前 10
])
```

### 常用阶段

| 阶段 | 作用 |
| --- | --- |
| `$match` | 过滤文档（尽早用，减少后续数据量） |
| `$group` | 分组聚合（sum/avg/max/min/first/push 等） |
| `$project` | 重塑字段（增删/计算/重命名） |
| `$sort` | 排序 |
| `$limit` / `$skip` | 分页 |
| `$lookup` | 跨集合关联（类 left join） |
| `$unwind` | 数组拆成多行 |
| `$facet` | 同一数据多管道并行聚合（多用于分页+统计） |
| `$bucket` | 按区间分桶 |

### `$group` 累加器

```javascript
{ $group: {
  _id: "$category",
  revenue: { $sum: "$price" },
  avgPrice: { $avg: "$price" },
  maxPrice: { $max: "$price" },
  users:    { $addToSet: "$userId" },   // 去重收集
  items:    { $push: "$name" }          // 全部收集
}}
```

### `$lookup` 关联查询

```javascript
db.orders.aggregate([
  { $match: { status: "PAID" } },
  { $lookup: {
      from: "users",
      localField: "userId",
      foreignField: "_id",
      as: "userInfo"
  }},
  { $unwind: "$userInfo" },
  { $project: { orderId: "$_id", user: "$userInfo.name", amount: 1 } }
])
```

> `$lookup` 性能好但有限制（同一数据库、内存限制 100MB，超需 `allowDiskUse: true`）。频繁 join 往往意味着建模该内嵌却没内嵌。

### 实战：多维度统计（facet 分页 + 总数）

```javascript
db.products.aggregate([
  { $match: { cat: "手机" } },
  { $facet: {
      metadata: [ { $count: "total" } ],
      data: [
        { $sort: { sales: -1 } },
        { $skip: 0 },
        { $limit: 20 }
      ]
  }}
])
```

## 六、索引 Hint 与执行计划

```javascript
// 强制使用某索引
db.users.find({ age: 30, city: "北京" }).hint({ city: 1, age: 1 })

// 查看执行计划
db.users.find({ age: 30 }).explain("executionStats")
```

聚合也可用 `explain()` 分析阶段开销。

## 七、批量写与性能

```javascript
// 批量写（有序/无序）
db.orders.bulkWrite([
  { insertOne: { document: { ... } } },
  { updateOne: { filter: { _id: 1 }, update: { $set: { x: 2 } } } },
  { deleteOne: { filter: { _id: 2 } } }
], { ordered: false })  // 无序可并行，更快
```
