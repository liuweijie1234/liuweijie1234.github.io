# Redis 基础入门与安装部署

> Redis（Remote Dictionary Server）是内存级键值数据库，以「极快读写 + 丰富数据结构」成为缓存、会话、排行榜、分布式锁的首选。本文覆盖认知、安装、连接、基础命令与排错。

---

## 1. Redis 是什么

- **内存存储**：数据主要驻留内存，读写微秒级；
- **键值模型**：Key 为字符串，Value 支持 String/Hash/List/Set/ZSet 等（见 第 2 章）；
- **单线程命令执行**：天然无锁、原子操作（见 第 3 章 为什么快）；
- **持久化可选**：RDB/AOF 落盘（见 第 4 章）；
- **高可用/分布式**：主从、哨兵、Cluster（见 第 7 章）。

适用：缓存、会话（Session）、计数器、排行榜、消息队列、分布式锁、限流。

## 2. 安装

### 2.1 Windows 安装

> Redis 官方不支持 Windows，社区版可用：<https://github.com/tporadowski/redis/releases>

管理工具推荐 **Redis Desktop Manager（RDM）**，可视化查看 Key 与内存。

### 2.2 WSL 连接 Windows 上的 Redis

```bash
# 查看版本
redis-cli info | grep redis_version
```

1. 修改配置文件 `redis.windows-service.conf`：
```bash
bind 0.0.0.0          # 允许所有 IP 连接
protected-mode no     # 关闭保护模式
```
2. 以管理员 PowerShell 重启服务：
```powershell
Stop-Service redis
Start-Service redis
```
3. 获取 Windows 主机 IP（WSL2 专用）：
```bash
cat /etc/resolv.conf | grep nameserver | awk '{print $2}'
# 如 172.28.112.1
```
4. WSL 中测试：
```bash
sudo apt install redis-tools
redis-cli -h 172.28.112.1 -p 6379
telnet 172.28.112.1 6379
```

### 2.3 macOS 安装（Homebrew）

```bash
brew install redis

# 临时启动（关终端即停）
redis-server

# 后台服务 + 开机自启（推荐）
brew services start redis

# 验证
redis-cli ping        # 返回 PONG 即正常
```

### 2.4 Docker 安装（环境隔离首选）

```bash
docker run --name my-redis -p 6379:6379 -d redis
docker exec -it my-redis redis-cli ping
```

### 2.5 配置文件

```bash
# macOS 配置位置
nano /usr/local/etc/redis.conf
```

常用项：

```ini
bind 0.0.0.0
protected-mode no
port 6379
daemonize yes
requirepass yourpassword     # 设置密码
maxmemory 2gb
maxmemory-policy allkeys-lru
```

## 3. 基础命令（Hello Redis）

```bash
redis-cli                      # 进入客户端
SELECT 0                       # 默认 16 个库，切库
SET name "Tom"                 # 写
GET name                       # 读 → "Tom"
SET counter 1
INCR counter                  # 原子自增 → 2
EXPIRE name 60                # 60 秒过期
TTL name                      # 查看剩余时间
KEYS user:*                   # 模糊匹配（生产慎用，用 SCAN 替代）
DEL name                      # 删除
FLUSHDB                       # 清当前库（慎用）
DBSIZE                        # Key 数量
```

> `KEYS` 会阻塞单线程，生产用 `SCAN` 游标迭代。

## 4. 常见问题

### Connection refused

```bash
brew services list | grep redis     # 是否运行
lsof -i :6379                        # 端口是否监听
```
- 确认 `redis-server` 已启动；
- 确认 `bind`/`protected-mode` 配置允许远程；
- 云服务器需开放安全组 6379。

### 卸载（macOS）

```bash
brew uninstall redis
brew cleanup
```
