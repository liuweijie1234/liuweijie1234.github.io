# Redis 数据类型与底层结构

> Redis 不只是「简单的 KV」。它提供 5 种基础类型 + 多种扩展类型，且每种类型在底层会根据数据量自动选用更高效的结构（如 ziplist → hashtable）。理解底层，才能选对类型、避坑调优。

---

## 1. 整体结构：RedisObject

每个 Value 在底层是一个 `redisObject`，含类型、编码（encoding）、引用计数与 LRU 时钟。Redis 根据数据规模在**多种编码间自动切换**，兼顾小数据省内存、大数据高性能。

```
redisObject {
  type:   string / hash / list / set / zset
  encoding: raw / embstr / int / ziplist / linkedlist / hashtable / skiplist ...
  ptr:    指向实际数据
}
```

---

## 2. String（字符串）

**底层编码**：`int`（整数）、`embstr`（≤44 字节短串）、`raw`（长串）。字符串底层是 **SDS（Simple Dynamic String）**，而非 C 字符串：

| SDS 优势 | 说明 |
| --- | --- |
| O(1) 取长度 | 记录 `len`，不用遍历 |
| 二进制安全 | 不依赖 `\0` 结尾，可存图片/序列化对象 |
| 杜绝缓冲区溢出 | 分配时自动扩展 |
| 空间预分配 | 减少重复扩容 |

常用命令：`SET/GET/INCR/APPEND/SETNX/MSET/EXPIRE`。

> 最大 512MB；`INCR` 是原子操作，天然适合计数器、分布式 ID。

---

## 3. Hash（哈希）

适合存对象（用户资料、商品属性）。

**底层编码**：
- 小数据：`ziplist`（压缩列表，省内存）或 `listpack`（7.0+ 取代 ziplist）；
- 大数据：`hashtable`（字典）。

```bash
HSET user:1 name Tom age 25
HGET user:1 name
HGETALL user:1
HINCRBY user:1 age 1
```

> 阈值（`hash-max-ziplist-entries` / `-value`）控制何时转 hashtable。

---

## 4. List（列表）

底层为 **quicklist**（3.2+）：`ziplist`（小段）组成的双向链表，兼顾省内存与首尾操作 O(1)。

```bash
LPUSH list a b c      # 左插 → [c,b,a]
RPUSH list d          # 右插
LPOP / RPOP           # 弹出
BLPOP list 5          # 阻塞弹出（实现简单队列）
LRANGE list 0 -1      # 范围取
```

应用：消息队列、最新消息、栈。

---

## 5. Set（集合）

无序、唯一。底层：`intset`（全整数且少）→ `hashtable`。

```bash
SADD tags a b c
SISMEMBER tags a       # 是否成员
SINTER s1 s2           # 交集（共同关注）
SUNION / SDIFF         # 并集 / 差集
```

应用：点赞、共同好友、去重。

---

## 6. ZSet（有序集合）

每个成员带 `score`，按 score 排序。底层：**跳表（skiplist）+ 字典（dict）** 双结构：

- `dict`：member → score，O(1) 查分；
- `skiplist`：按 score 有序，支持范围、排名。

```
跳表：多层有序链表，每层随机"跨度"，查找接近二分
level 3:  head ──────────────────→ 50
level 2:  head ───→ 20 ─────────→ 50
level 1:  head → 10 → 20 → 30 → 50
```

```bash
ZADD rank 100 Tom 200 Jerry 150 Bob
ZRANGE rank 0 -1 WITHSCORES        # 按分升序
ZREVRANGE rank 0 9                 # 排行榜 Top10
ZRANK rank Tom                     # 排名
ZINCRBY rank 10 Tom                # 加分
```

应用：排行榜、延迟队列、优先级队列。

---

## 7. 扩展类型

| 类型 | 说明 | 应用 |
| --- | --- | --- |
| Bitmap | 位操作（SETBIT/BITCOUNT） | 签到、在线状态、布隆过滤 |
| HyperLogLog | 基数估计（误差 ~0.81%） | UV 统计（省内存） |
| GEO | 地理坐标 zset 实现 | 附近的人、距离 |
| Stream | 持久化、可消费组日志 | 消息队列（替代 List 的高级方案） |

```bash
SETBIT sign:202401 1 1     # 第1天签到
BITCOUNT sign:202401        # 当月签到天数
GEOADD riders 116.40 39.9 u1
GEORADIUS riders 116.40 39.9 5 km
```

---

## 8. 选型建议

- 单值/计数/分布式锁 → **String**；
- 对象（多字段）→ **Hash**；
- 队列/最新列表 → **List**；
- 去重/交集 → **Set**；
- 排序/排行 → **ZSet**；
- 大数据量 Value（如大 JSON）注意拆分，避免**大 Key**（见 第 8 章）。
