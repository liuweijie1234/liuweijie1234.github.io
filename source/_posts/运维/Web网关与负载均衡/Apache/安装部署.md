# Apache 安装部署

Apache HTTP Server（httpd）是老牌 Web 服务器，模块丰富、稳定可靠。以下为常见发行版的安装方式。

## 安装

```bash
# Debian/Ubuntu
apt-get install -y apache2

# RHEL/CentOS 7
yum install -y httpd

# RHEL/CentOS 8+ / Rocky
dnf install -y httpd
```

## 目录结构

| 路径 | 说明（Debian / RHEL） |
| --- | --- |
| 主配置 | `/etc/apache2/apache2.conf` / `/etc/httpd/conf/httpd.conf` |
| 站点配置 | `/etc/apache2/sites-available` + `sites-enabled` / `/etc/httpd/conf.d/*.conf` |
| 模块配置 | `/etc/apache2/mods-available` + `mods-enabled` / 编译进核心 |
| 站点根目录 | `/var/www/html` |
| 日志 | `/var/log/apache2/*` / `/var/log/httpd/*` |

## 启动与管理

```bash
# Debian/Ubuntu
systemctl enable --now apache2
a2ensite  mysite.conf      # 启用站点（建软链到 sites-enabled）
a2dissite mysite.conf      # 停用站点
a2enmod   ssl rewrite      # 启用模块

# RHEL/CentOS
systemctl enable --now httpd
```

## 验证

```bash
apachectl configtest       # 语法检测（Debian 也可 apache2ctl -t）
curl -I http://localhost   # 返回 200 即成功
httpd -v                   # 查看版本
```

## 第一个虚拟主机示例（Debian）

`/etc/apache2/sites-available/example.conf`：

```apache
<VirtualHost *:80>
    ServerName example.com
    DocumentRoot /var/www/example
    <Directory /var/www/example>
        AllowOverride All
        Require all granted
    </Directory>
    ErrorLog ${APACHE_LOG_DIR}/example_error.log
    CustomLog ${APACHE_LOG_DIR}/example_access.log combined
</VirtualHost>
```

启用：`a2ensite example && systemctl reload apache2`。
