# Apache 性能优化

Apache 性能主要取决于 **MPM（多路处理模块）** 的选择与参数调优，以及合理的缓存、压缩与连接设置。

## MPM 模型选择

| MPM | 特点 | 适用 |
| --- | --- | --- |
| `prefork` | 多进程、每进程一线程，稳定但内存占用高 | 老模块/非线程安全（如部分 PHP） |
| `worker` | 多进程 + 多线程，内存友好 | 中等并发 |
| `event` | 在 worker 基础上用异步处理空闲连接，性能最佳 | 高并发、长连接（推荐） |

查看当前 MPM：`httpd -V | grep -i mpm`。切换（RHEL 编辑 `/etc/httpd/conf.modules.d/00-mpm.conf`，Debian 用 `a2dismod mpm_prefork && a2enmod mpm_event`）。

## event MPM 调优

```apache
<IfModule mpm_event_module>
    StartServers             3
    MinSpareThreads         75
    MaxSpareThreads        250
    ThreadsPerChild         25
    MaxRequestWorkers      400     # 最大并发请求数（核心参数）
    MaxConnectionsPerChild   0     # 0 表示子进程不限请求数
</IfModule>
```

- `MaxRequestWorkers`（旧版 `MaxClients`）：控制最大并发，值 = `ThreadsPerChild × 进程数`。调大前需确认内存够用（每进程约 10–30MB）。
- `ServerLimit`：进程数上限，需 ≥ `MaxRequestWorkers / ThreadsPerChild`。

## 启用压缩（mod_deflate）

```apache
<IfModule mod_deflate.c>
    AddOutputFilterByType DEFLATE text/html text/css application/javascript application/json
    DeflateCompressionLevel 6
</IfModule>
```

## 开启缓存与过期头

```apache
<IfModule mod_expires.c>
    ExpiresActive On
    ExpiresByType image/png  "access plus 30 days"
    ExpiresByType text/css   "access plus 7 days"
    ExpiresByType application/javascript "access plus 7 days"
</IfModule>
```

## 连接与超时

```apache
Timeout 60                 # 请求超时（秒）
KeepAlive On               # 复用 TCP 连接
MaxKeepAliveRequests 100   # 单连接最大请求数
KeepAliveTimeout 5         # 长连接空闲超时
```

## 关闭不必要模块

减少加载的模块可降低内存与攻击面：`a2dismod status autoindex cgi`（按需）。

## 性能监控（server-status）

```apache
<Location "/server-status">
    SetHandler server-status
    Require ip 10.0.0.0/8
</Location>
ExtendedStatus On
```

访问 `http://host/server-status` 查看当前请求、吞吐量、各进程状态；也可被监控采集（见 [监控与可观测性](../../监控与可观测性/readme.md)）。
