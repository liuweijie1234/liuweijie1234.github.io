# Apache 日志详解

Apache 主要有两类日志：**访问日志（access log）**与**错误日志（error log）**，是排障与流量分析的第一手数据。

## 日志格式

访问日志格式由 `LogFormat` 定义，`combined` 为最常见：

```
LogFormat "%h %l %u %t \"%r\" %>s %b \"%{Referer}i\" \"%{User-Agent}i\"" combined
CustomLog logs/access_log combined
```

字段含义：

| 占位符 | 含义 |
| --- | --- |
| `%h` | 客户端 IP |
| `%l` | 远程登录名（通常为 `-`） |
| `%u` | 认证用户（未认证为 `-`） |
| `%t` | 请求时间 |
| `%r` | 请求行（方法 + URI + 协议） |
| `%>s` | 响应状态码 |
| `%b` | 响应字节数（不含头） |
| `%{Referer}i` | 来源页 |
| `%{User-Agent}i` | 客户端浏览器/代理 |

示例日志行：

```
10.0.0.5 - - [30/Jul/2026:10:12:33 +0800] "GET /api/list HTTP/1.1" 200 1234 "https://example.com/" "Mozilla/5.0"
```

错误日志级别由 `LogLevel` 控制（`error`、`warn`、`notice`、`info`、`debug`）。

## 常用分析命令

```bash
# 统计各状态码数量
awk '{print $9}' access_log | sort | uniq -c | sort -rn

# 统计访问最多的 IP（TOP 10）
awk '{print $1}' access_log | sort | uniq -c | sort -rn | head

# 统计最热 URL
awk '{print $7}' access_log | sort | uniq -c | sort -rn | head

# 查看 5xx 错误
grep ' 5[0-9][0-9] ' access_log | head

# 某 IP 的访问明细
grep '^10\.0\.0\.5 ' access_log
```

## 日志切割

避免单个日志无限增长，使用 `rotatelogs`（Apache 自带）或 `logrotate`：

```apache
# rotatelogs：每日切割，保留 30 天
CustomLog "|/usr/sbin/rotatelogs /var/log/httpd/access_%Y%m%d.log 86400" combined
```

`/etc/logrotate.d/httpd` 示例：

```
/var/log/httpd/*log {
    daily
    missingok
    rotate 30
    compress
    delaycompress
    sharedscripts
    postrotate
        /bin/systemctl reload httpd > /dev/null 2>&1 || true
    endscript
}
```

## 可视化分析

- `goaccess`：终端实时分析，`goaccess access_log -o report.html --log-format=COMBINED`。
- 接入 ELK（Filebeat → Logstash → Elasticsearch → Kibana）做集中分析与告警。详见 [ELK](../../监控与可观测性/ELK/readme.md)。
