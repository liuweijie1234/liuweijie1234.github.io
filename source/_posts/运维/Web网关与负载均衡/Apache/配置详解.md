# Apache 配置文件详解

Apache 配置以**指令（directive）**为核心，通过全局配置、虚拟主机（VirtualHost）、目录块（Directory）与 `.htaccess` 组合实现灵活控制。

## 全局核心指令

```apache
ServerRoot "/etc/httpd"          # 服务根目录
Listen 80                        # 监听端口（可多个）
ServerAdmin admin@example.com    # 管理员邮箱
ServerName www.example.com:80    # 服务器名，避免启动警告
DocumentRoot "/var/www/html"     # 默认站点根目录
ErrorLog "logs/error_log"        # 错误日志
LogLevel warn                    # 日志级别
```

## 虚拟主机（VirtualHost）

一台服务器托管多个站点：

```apache
<VirtualHost *:80>
    ServerName   a.example.com
    DocumentRoot /var/www/a
    ErrorLog  /var/log/httpd/a_error.log
    CustomLog   /var/log/httpd/a_access.log combined
</VirtualHost>

<VirtualHost *:443>
    ServerName   b.example.com
    DocumentRoot /var/www/b
    SSLEngine on
    SSLCertificateFile      /path/cert.pem
    SSLCertificateKeyFile   /path/key.pem
</VirtualHost>
```

## 目录与访问控制

```apache
<Directory "/var/www/html">
    Options Indexes FollowSymLinks     # Indexes 允许目录浏览（生产建议关闭）
    AllowOverride All                  # 允许 .htaccess 覆盖
    Require all granted                # 允许所有访问
    # Require ip 10.0.0.0/8           # 仅允许内网
</Directory>

<Files ".env">
    Require all denied                 # 禁止访问敏感文件
</Files>
```

## .htaccess 目录级配置

`.htaccess` 放在站点目录下，可无需 reload 即时生效（但每次请求都需读取，略有性能损耗）：

```apache
# 开启 rewrite
RewriteEngine On
# 强制 HTTPS
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
# 伪静态：/post/123 -> /index.php?p=123
RewriteRule ^post/([0-9]+)$ index.php?p=$1 [L]
```

## 常用模块

| 模块 | 作用 | 启用 |
| --- | --- | --- |
| `mod_rewrite` | URL 重写 | `a2enmod rewrite` |
| `mod_ssl` | HTTPS | `a2enmod ssl` |
| `mod_proxy` + `mod_proxy_http` | 反向代理 | `a2enmod proxy proxy_http` |
| `mod_headers` | 自定义响应头 | `a2enmod headers` |
| `mod_deflate` | 响应压缩 | `a2enmod deflate` |

## 反向代理示例

```apache
<VirtualHost *:80>
    ServerName api.example.com
    ProxyPreserveHost On
    ProxyPass        / http://127.0.0.1:8080/
    ProxyPassReverse / http://127.0.0.1:8080/
</VirtualHost>
```

## 配置校验

```bash
apachectl configtest     # 输出 Syntax OK 即无误
```

修改后 `systemctl reload httpd`（或 `graceful`）平滑生效。
