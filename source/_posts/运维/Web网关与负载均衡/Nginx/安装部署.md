# Nginx 安装部署

Nginx 官方提供预编译包与源码编译两种方式。生产环境推荐使用官方仓库，版本更新且带安全补丁。

## 使用官方仓库安装（推荐）

```bash
# Ubuntu/Debian
apt-get install -y curl gnupg2 ca-certificates lsb-release
curl -fsSL https://nginx.org/keys/nginx_signing.key | gpg --dearmor -o /usr/share/keyrings/nginx-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/nginx-archive-keyring.gpg] http://nginx.org/packages/ubuntu $(lsb_release -cs) nginx" \
  > /etc/apt/sources.list.d/nginx.list
apt-get update && apt-get install -y nginx

# RHEL/CentOS
cat > /etc/yum.repos.d/nginx.repo <<'EOF'
[nginx-stable]
name=nginx stable repo
baseurl=http://nginx.org/packages/centos/$releasever/$basearch/
gpgcheck=1
enabled=1
gpgkey=https://nginx.org/keys/nginx_signing.key
EOF
yum install -y nginx
```

## 源码编译安装

```bash
yum install -y gcc pcre-devel zlib-devel openssl-devel
wget https://nginx.org/download/nginx-1.26.2.tar.gz
tar -xzf nginx-1.26.2.tar.gz && cd nginx-1.26.2
./configure --prefix=/usr/local/nginx \
  --with-http_ssl_module --with-http_v2_module \
  --with-http_gzip_static_module --with-http_stub_status_module
make && make install
```

常用编译模块：`--with-http_ssl_module`（HTTPS）、`--with-http_v2_module`（HTTP/2）、`--with-http_stub_status_module`（状态监控）、`--add-module`（第三方模块如 echo、lua）。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `/etc/nginx/nginx.conf` | 主配置文件 |
| `/etc/nginx/conf.d/*.conf` | 子配置（默认 `include` 引入） |
| `/var/log/nginx/access.log` | 访问日志 |
| `/var/log/nginx/error.log` | 错误日志 |
| `/usr/share/nginx/html` | 默认站点根目录 |

## 启动与管理

```bash
systemctl enable --now nginx     # 开机自启并启动
nginx -t                         # 测试配置语法
nginx -s reload                  # 平滑重载
nginx -s stop                    # 快速停止
nginx -s quit                    # 优雅退出
```

## 验证

```bash
curl -I http://localhost        # 返回 200 即成功
nginx -v                         # 查看版本
```
