# Docker 快速入门

Docker 把应用及其依赖打包进**容器**（轻量、可移植、隔离），实现"一次构建，到处运行"。本篇帮助你半小时内跑通第一个容器。

## 核心概念

- **镜像（Image）**：只读模板，包含运行应用所需的文件系统与配置。
- **容器（Container）**：镜像的运行实例，可读写层在镜像之上。
- **仓库（Registry）**：存储与分发镜像，如 Docker Hub、私有 Harbor。
- **Dockerfile**：构建镜像的脚本。
- **Volume / Network**：持久化存储与容器间网络。

## 安装（简述）

```bash
# 使用官方脚本（生产建议按需调整）
curl -fsSL https://get.docker.com | sh
systemctl enable --now docker

# 验证
docker version
docker run hello-world
```

详细安装见 [安装部署](安装部署.md)。

## 第一个容器

```bash
# 拉取并运行 Nginx，映射 8080->80，后台运行
docker run -d --name mynginx -p 8080:80 nginx:stable
curl http://localhost:8080

# 进入容器
docker exec -it mynginx sh

# 停止并删除
docker stop mynginx && docker rm mynginx
```

## 常用入门命令

```bash
docker ps -a                 # 查看所有容器（含已停止）
docker images                # 查看本地镜像
docker logs -f mynginx       # 跟踪日志
docker inspect mynginx       # 查看详情（IP、挂载、配置）
docker rm -f $(docker ps -aq)  # 强制清理全部容器
```

## 构建第一个镜像

`Dockerfile`：

```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install --production
COPY . .
EXPOSE 3000
CMD ["node", "server.js"]
```

构建与运行：

```bash
docker build -t myapp:1.0 .
docker run -d -p 3000:3000 myapp:1.0
```
