# Docker 网络与存储

Docker 通过可插拔的网络驱动与存储机制，为容器提供隔离的通信环境与持久化能力。

## 网络模式

| 模式 | 说明 | 适用场景 |
| --- | --- | --- |
| `bridge`（默认） | 容器挂在 `docker0` 网桥，通过 NAT 访问外网，容器间经网桥互通 | 单机多容器 |
| `host` | 直接使用宿主机网络命名空间，无 NAT，性能最好 | 对网络性能敏感、无需隔离 |
| `none` | 无网络，仅回环 | 纯计算/离线任务 |
| `container` | 共享另一容器的网络栈 | 网络旁路（如 sidecar） |
| `overlay` | 跨主机容器网络（依赖 Swarm/K8s） | 多主机集群 |

## 自定义网络与容器互联

```bash
# 创建自定义 bridge 网络
docker network create mynet

# 容器接入同一网络，可用容器名互相访问（内置 DNS）
docker run -d --name db --network mynet redis
docker run -d --name web --network mynet -p 8080:80 myapp
# 在 web 容器内可直接访问 db:6379
```

> 默认 `bridge` 网络不支持容器名解析，应使用自定义网络。

## 端口映射与 DNS

```bash
docker run -p 8080:80 -p 8443:443 nginx      # 主机端口:容器端口
docker run -P myapp                            # 自动映射 EXPOSE 的端口
docker network inspect mynet                  # 查看网络与容器 IP
```

## 存储驱动与数据持久化

Docker 使用**存储驱动**（overlay2 默认）管理镜像层和容器可写层。容器可写层随容器删除而丢失，持久化数据必须用 Volume 或 Bind mount。

```bash
docker volume ls                      # 列出卷
docker volume inspect data            # 查看卷详情（实际路径）
docker volume rm data                 # 删除卷（注意数据一并删除）
docker volume prune                   # 清理未使用的卷
```

## 卷管理与备份

```bash
# 备份卷：用临时容器把卷打包
docker run --rm -v data:/data -v $(pwd):/backup alpine \
  tar czf /backup/data.tar.gz -C /data .

# 恢复卷
docker run --rm -v data:/data -v $(pwd):/backup alpine \
  tar xzf /backup/data.tar.gz -C /data
```

## 跨主机 overlay 网络（Swarm 示例）

```bash
docker swarm init
docker network create -d overlay myoverlay
# 各节点加入 swarm 后，服务可跨主机同网络互通
```

## 排障

```bash
docker network inspect bridge        # 检查网桥与 IP 分配
docker exec -it web ping db          # 测试容器间连通性
iptables -t nat -L -n                # 查看 Docker 生成的 NAT 规则
# 端口冲突：netstat -tlnp | grep 8080
```
