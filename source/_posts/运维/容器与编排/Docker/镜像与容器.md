# Docker 镜像与容器

镜像与容器是 Docker 的核心对象。理解镜像分层、Dockerfile 编写与容器生命周期，是高效使用 Docker 的基础。

## 镜像分层与联合文件系统

- 镜像由多个**只读层（layer）**叠加而成，每一层对应 Dockerfile 中的一条指令。
- 容器运行时在镜像顶层加一个**可写层（container layer）**，所有写操作都在该层。
- 多个镜像可共享相同的基础层，节省磁盘与传输。
- 底层基于 UnionFS（overlay2 为当前默认存储驱动）。

## Dockerfile 编写

```dockerfile
FROM ubuntu:22.04                # 基础镜像
LABEL maintainer="ops@example.com"
ENV TZ=Asia/Shanghai            # 环境变量
WORKDIR /app                    # 工作目录
COPY . /app                     # 复制文件
RUN apt-get update && apt-get install -y python3 && rm -rf /var/lib/apt/lists/* \
    && pip install -r requirements.txt   # 合并 RUN 减少层数
EXPOSE 8000                     # 声明端口
CMD ["python3", "app.py"]       # 容器启动命令
```

### FROM / RUN / COPY / CMD / ENTRYPOINT 区别

| 指令 | 作用 |
| --- | --- |
| `FROM` | 指定基础镜像（必须为第一条非注释指令） |
| `RUN` | 构建时执行命令，生成新层 |
| `COPY`/`ADD` | 复制文件进镜像（`ADD` 支持 URL 与自动解压 tar） |
| `CMD` | 容器默认启动命令，可被 `docker run` 参数覆盖 |
| `ENTRYPOINT` | 容器入口，与 `CMD` 组合传参，不易被覆盖 |

> `ENTRYPOINT` + `CMD`：`ENTRYPOINT` 定可执行程序，`CMD` 作默认参数。

## 镜像构建与优化

```bash
docker build -t myapp:1.0 .
docker build -t myapp:1.0 -f Dockerfile.prod .
docker build --no-cache -t myapp:1.0 .   # 不使用缓存重新构建
```

优化建议：

- **多阶段构建**：编译与运行分离，最终镜像仅含运行时依赖。
  ```dockerfile
  FROM golang:1.22 AS build
  WORKDIR /src && COPY . . && RUN go build -o app .
  FROM alpine:3.20
  COPY --from=build /src/app /usr/local/bin/app
  CMD ["app"]
  ```
- **利用缓存**：变动少的指令（如依赖安装）放前面，`COPY` 源码放后面。
- **减小体积**：选 `alpine`/`slim` 基础镜像，清理 apt/yum 缓存。
- **`.dockerignore`**：排除 `.git`、`node_modules` 等，避免无关文件进上下文。

## 容器生命周期

```bash
docker create myapp:1.0          # 创建（不启动）
docker start <id>                # 启动
docker stop  <id>                # 优雅停止（SIGTERM）
docker kill  <id>                # 强制停止（SIGKILL）
docker restart <id>              # 重启
docker pause <id> / unpause      # 暂停/恢复
docker rm    <id>                # 删除（需先 stop）
docker run = create + start
```

## 数据卷与绑定挂载

```bash
docker volume create data                 # 创建命名卷
docker run -v data:/var/lib/mysql mysql   # 命名卷挂载
docker run -v /host/path:/container/path  nginx   # 绑定挂载主机目录
docker run --rm -v $(pwd):/wk -w /wk node npm test  # 临时挂载
```

- **Volume**：由 Docker 管理，适合数据库等需要持久化的数据。
- **Bind mount**：直接映射主机目录，适合开发调试、配置文件挂载。

## 镜像仓库（push / pull）

```bash
docker login registry.example.com
docker tag myapp:1.0 registry.example.com/ops/myapp:1.0
docker push registry.example.com/ops/myapp:1.0
docker pull registry.example.com/ops/myapp:1.0
```

> 镜像导出/导入（无仓库时）：`docker save myapp:1.0 -o app.tar` / `docker load -i app.tar`。
