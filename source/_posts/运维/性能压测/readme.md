# 性能压测

压测用于评估系统容量、发现性能瓶颈。本模块覆盖轻量级命令行压测工具与重量级压测平台。

## 命令行工具

- [ApacheBench (ab)](ApacheBench.md)
- [Siege](Siege.md)
- [wrk](wrk.md) 高性能 HTTP 压测，支持 Lua 脚本
- [JMeter](JMeter.md) 图形化、多线程、支持复杂场景与分布式压测
