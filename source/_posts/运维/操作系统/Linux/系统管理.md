# Linux 系统管理

系统管理是运维的日常，涵盖进程、内存、磁盘、网络与日志排障。掌握这些工具能快速定位线上问题。

## 进程管理

```bash
ps aux | grep nginx              # 查看进程与资源占用
ps -ef --forest                  # 树状显示进程关系
top / htop                       # 实时监控（htop 更友好）
pidof nginx                     # 取进程 PID
kill -15 <pid>                  # 优雅终止（SIGTERM）
kill -9  <pid>                  # 强制终止（SIGKILL，慎用）
renice -n 10 -p <pid>           # 调整优先级（nice 值 -20~19，越小越高）
nohup cmd &                     # 脱离终端后台运行
```

- **前台/后台**：`cmd &` 后台；`Ctrl+Z` 挂起；`jobs`、`fg`、`bg` 切换。
- **僵尸进程**：父进程未回收子进程，需重启父进程。

## 内存管理

```bash
free -h                         # 内存与 swap 概览
vmstat 1                        # 进程、内存、IO、CPU 每秒刷新
cat /proc/meminfo               # 详细内存信息
pmap -x <pid>                   # 某进程内存映射
```

- `available` 才是真正可用内存（含可回收的 cache/buffer）。
- 频繁 swap 通常意味着物理内存不足。
- **OOM**：`dmesg | grep -i oom` 查看被内核杀掉的进程；调 `vm.overcommit_memory`/`oom_score_adj` 可干预。

## 磁盘管理

```bash
df -h                           # 各挂载点使用率
du -sh /var/log                # 目录占用
du -h --max-depth=1 /var       # 一层子目录占用
ls -i file                     # 查看 inode
df -i                          # inode 使用率（满则无法建文件）
iostat -x 1                    # 磁盘 IO（需 sysstat）
fdisk -l /dev/sdb              # 查看分区
mkfs.ext4 /dev/sdb1            # 格式化
mount /dev/sdb1 /data          # 挂载
```

- 磁盘满优先排查大日志/核心转储：`du -sh /var/* | sort -h`。
- inode 满常见于海量小文件（如邮件、缓存）。

## 网络管理

```bash
ip addr / ip link              # 网卡与 IP
ip route                       # 路由表
ss -tulpn                      # 监听端口与进程（推荐替代 netstat）
ss -tnp state established     # 已建立连接
ping -c 4 host                 # 连通性
traceroute host / mtr host    # 路由追踪与丢包
dig example.com / nslookup    # DNS 解析
curl -I http://host            # HTTP 探测
tcpdump -i eth0 port 80 -nn    # 抓包
```

- 连通性问题排查链路：本机 IP/路由 → 网关 → DNS → 对端端口/防火墙。
- 大量 `TIME_WAIT`：调 `net.ipv4.tcp_tw_reuse=1`；连接数上不去检查 `nf_conntrack` 与文件描述符。

## 系统资源与性能

- `uptime` / `cat /proc/loadavg`：负载（1/5/15 分钟）。负载 ≈ 运行态+等待 IO 的进程数，正常应 < CPU 核数。
- `/proc` 关键文件：
  - `/proc/loadavg`：负载
  - `/proc/meminfo`：内存
  - `/proc/cpuinfo`：CPU
  - `/proc/<pid>/status`：进程状态、内存
- 综合性能：`perf top`、`strace -p <pid>`（系统调用）、`sar -u 1`（历史采样，sysstat）。

## 日志与排障

```bash
journalctl -xe                  # systemd 日志（最近错误）
journalctl -u nginx -f          # 跟踪某服务
dmesg -T | tail                 # 内核环缓冲（硬件/驱动/OOM）
tail -f /var/log/syslog         # 系统日志（Debian）
tail -f /var/log/messages       # 系统日志（RHEL）
cat /var/log/secure             # 登录认证日志（RHEL）
```

排障思路：先确认现象（CPU/内存/IO/网络哪类瓶颈）→ 定位进程/连接 → 看日志与调用栈 → 复现与验证。
