# Grafana 安装部署

Grafana 是开源的可视化与告警平台，支持 Prometheus、Elasticsearch、MySQL、Loki 等数十种数据源，是监控大盘与告警的统一入口。

## Linux 安装（推荐）

```bash
# Debian/Ubuntu
apt-get install -y apt-transport-https software-properties-common
wget -q -O - https://apt.grafana.com/gpg.key | gpg --dearmor -o /usr/share/keyrings/grafana.gpg
echo "deb [signed-by=/usr/share/keyrings/grafana.gpg] https://apt.grafana.com stable main" \
  > /etc/apt/sources.list.d/grafana.list
apt-get update && apt-get install -y grafana

# RHEL/CentOS
cat > /etc/yum.repos.d/grafana.repo <<'EOF'
[grafana]
name=grafana
baseurl=https://rpm.grafana.com
gpgcheck=1
gpgkey=https://rpm.grafana.com/gpg.key
enabled=1
EOF
yum install -y grafana
```

启动：

```bash
systemctl enable --now grafana-server
# 默认监听 3000，初始账号 admin/admin，首次登录要求改密码
```

配置文件：`/etc/grafana/grafana.ini`，可改端口、数据库（默认 SQLite）、匿名访问、SMTP 等。

## Docker 安装

```bash
docker run -d -p 3000:3000 \
  -v grafana-storage:/var/lib/grafana \
  --name grafana grafana/grafana
```

## Windows 安装

下载地址：https://grafana.com/grafana/download
安装文档：https://grafana.com/docs/grafana/latest/installation/windows/

解压后运行 `bin/grafana-server.exe` 即可，配置文件为 `conf/defaults.ini`（可复制为 `custom.ini` 覆盖）。

## 添加数据源（Prometheus）

1. 登录 → Connections → Data sources → Add data source → Prometheus。
2. URL 填 `http://prometheus:9090`，Scrape interval 默认，Save & test。
3. 新建 Dashboard → Add panel，查询写 PromQL（如 `rate(http_requests_total[5m])`）。

## 仪表盘模板

- 官方模板库：https://grafana.com/grafana/dashboards/
- 常用：Node Exporter Full（ID 1860）、Kubernetes（ID 3119）、MySQL Overview。
- 导入：Dashboard → Import，粘贴模板 ID 或 JSON，选择数据源即可。

## 告警（Alerting）

- Grafana 9+ 统一告警引擎，可在面板直接加 Threshold 或 Expression。
- 支持通知渠道：邮件、Slack、Webhook、钉钉/飞书（通过 webhook 机器人）。
- 告警规则与 Prometheus 原生告警可并存，建议统一出口避免重复。

## 生产建议

- 用户与权限：启用 `auth` 并接入 LDAP/OAuth，按需分配 Editor/Viewer 角色。
- 数据持久化：容器部署务必挂卷，避免容器重建丢失仪表盘。
- 高可用：企业版支持多副本 + 共享数据库（MySQL/PostgreSQL）+ 对象存储（镜像缓存）。
- 反向代理：建议置于 Nginx 之后并启用 HTTPS，详见 [Nginx HTTPS](../../Web网关与负载均衡/Nginx/HTTPS与性能优化.md)。
