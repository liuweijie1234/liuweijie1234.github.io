# Zabbix 安装部署

Zabbix 是企业级开源监控系统，支持 Agent / SNMP / JMX / IPMI 等多种采集方式，内置图形、触发器、告警与自动发现，适合传统 IT 基础设施监控。

## 架构概览

- **Zabbix Server**：核心，负责采集调度、计算触发器、告警。
- **Database**：存储配置、历史数据与趋势（MySQL / PostgreSQL）。
- **Zabbix Web**：前端（PHP），提供 UI 与配置入口。
- **Zabbix Agent**：安装在被监控主机，采集本地指标（主动/被动模式）。
- **Proxy**（可选）：分布式采集，减轻 Server 压力，适合多机房。

## 服务端安装（CentOS 示例）

```bash
# 添加仓库
rpm -Uvh https://repo.zabbix.com/zabbix/6.0/rhel/7/x86_64/zabbix-release-6.0-4.el7.noarch.rpm
yum install -y zabbix-server-mysql zabbix-web-mysql zabbix-apache-conf zabbix-agent

# 准备数据库
mysql -uroot -p
CREATE DATABASE zabbix CHARACTER SET utf8mb4 COLLATE utf8mb4_bin;
CREATE USER 'zabbix'@'localhost' IDENTIFIED BY 'password';
GRANT ALL ON zabbix.* TO 'zabbix'@'localhost';
quit
zcat /usr/share/doc/zabbix-server-mysql*/create.sql.gz | mysql -uzabbix -p zabbix

# 配置 Server 连接数据库
vim /etc/zabbix/zabbix_server.conf
# DBHost=localhost  DBName=zabbix  DBUser=zabbix  DBPassword=password

# 启动
systemctl enable --now zabbix-server zabbix-agent httpd
```

Web 访问 `http://<server>/zabbix`，按向导完成初始化（填入数据库信息）。

## Agent 安装与被监控端

```bash
# 被监控主机安装 agent
yum install -y zabbix-agent
vim /etc/zabbix/zabbix_agentd.conf
# Server=<Zabbix Server IP>
# ServerActive=<Zabbix Server IP>
# Hostname=<本机唯一名>
systemctl enable --now zabbix-agent
```

- **被动模式**：Server 主动来拉数据（默认）。
- **主动模式**：Agent 主动上报，适合跨防火墙/大批量。

## Web 端配置流程

1. Configuration → Hosts → Create host：填 Hostname、Groups、Agent 接口（IP:10050）。
2. Templates → 关联模板（如 `Template OS Linux by Zabbix agent`）。
3. Monitoring → Latest data：查看指标。
4. Configuration → Hosts 勾选模板后自动采集；触发器（Trigger）触发后在 Monitoring → Problems 看到告警。

## 触发器与告警

- 触发器基于表达式：`{Host:item.last()}>90`（如磁盘使用率 > 90% 告警）。
- 告警动作：Administration → Media types 配置邮件/Webhook；Configuration → Actions 定义触发后通知谁。
- 支持自动发现（Discovery）批量纳管网段内主机。

## Windows 安装

下载：https://www.zabbix.com/download
文档：https://www.zabbix.com/documentation/6.0/zh/manual
安装后修改 `C:\Program Files\Zabbix Agent\zabbix_agentd.conf` 的 `Server`/`Hostname`，启动服务即可。

## 与 Prometheus 的取舍

- **Zabbix**：开箱即用的主机/网络监控，模板生态成熟，传统运维友好。
- **Prometheus**：云原生、拉模型、PromQL 灵活，适合容器与动态环境。
- 两者可共存：Zabbix 管基础设施，Prometheus + Grafana 管 K8s 与指标可视化。
