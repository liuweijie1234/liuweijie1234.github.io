# 高可用与集群架构

本模块将 [运维面试题](../面试题.md) 中的高负载、高可用、集群、容灾要点展开为系统化知识索引，是运维进阶与面试准备的重点。

## 一、高负载与高可用基础

- QPS / PV / UV、留存用户、活跃用户等指标定义
- 流量、带宽与容量评估
- 负载均衡结构图（接入层 → 网关层 → 服务层 → 数据层 → 缓存层）
- 高可用的核心思路：冗余 + 故障转移（Failover）

## 二、负载均衡

- 四层（LVS）与七层（Nginx / HAProxy）负载均衡
- Nginx 负载均衡策略：轮询、加权轮询、IP Hash、最少连接
- 健康检查与熔断

## 三、集群与容灾

- 服务集群水平扩展
- 数据库主从、读写分离、分库分表
- 多机房 / 异地多活 / 容灾预案（RTO / RPO）

## 四、缓存与高并发架构

- 缓存层（Redis）设计与击穿 / 穿透 / 雪崩防护
- 异步化与消息队列削峰
- CDN 与静态资源分流

## 五、计算机网络（面试高频）

- HTTP/1.1 / 2 / 3 演进
- HTTPS 与 TLS 握手
- TCP 三次握手 / 四次挥手、长连接
- Cookie / Session / JWT
- 跨域（CORS）与接口安全

## 六、操作系统核心（面试高频）

- 进程与线程的区别
- IO 多路复用：select / poll / epoll
- 内存分页机制
